🧠 Key Concepts

Monitoring → Knowing the health and performance of systems.

Metrics → Numeric measurements collected over time.

Prometheus → Collects and stores time-series metrics.

PromQL → Query language used to retrieve and analyze Prometheus metrics.

Grafana → Visualizes metrics through dashboards.

Alertmanager → Handles and routes alerts generated from Prometheus rules.

Observability → Understanding internal system behavior through telemetry such as metrics, logs and traces.
