🐳 1. Dockerfile

Basic Dockerfile

FROM nginx:alpine

COPY . /usr/share/nginx/html

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]

Node.js Application

FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm ci

COPY . .

EXPOSE 3000

CMD ["npm", "start"]
Possible interview question: Write a Dockerfile for an application.

☸️ 2. Kubernetes Manifests

Deployment

apiVersion: apps/v1
kind: Deployment

metadata:
  name: myapp

spec:
  replicas: 3

  selector:
    matchLabels:
      app: myapp

  template:

    metadata:
      labels:
        app: myapp

    spec:

      containers:
        - name: myapp
          image: nginx:latest

          ports:
            - containerPort: 80

Service

apiVersion: v1
kind: Service

metadata:
  name: myapp-service

spec:

  selector:
    app: myapp

  ports:
    - port: 80
      targetPort: 80

  type: ClusterIP

ConfigMap

apiVersion: v1
kind: ConfigMap

metadata:
  name: app-config

data:
  APP_ENV: "production"
  APP_NAME: "myapp"

Secret

apiVersion: v1
kind: Secret

metadata:
  name: app-secret

type: Opaque

stringData:
  DB_USERNAME: admin
  DB_PASSWORD: password

Ingress

apiVersion: networking.k8s.io/v1
kind: Ingress

metadata:
  name: myapp-ingress

spec:

  rules:

    - host: myapp.example.com

      http:

        paths:

          - path: /
            pathType: Prefix

            backend:

              service:
                name: myapp-service

                port:
                  number: 80

HPA

apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler

metadata:
  name: myapp-hpa

spec:

  scaleTargetRef:

    apiVersion: apps/v1
    kind: Deployment
    name: myapp

  minReplicas: 2
  maxReplicas: 5

  metrics:

    - type: Resource

      resource:

        name: cpu

        target:

          type: Utilization
          averageUtilization: 70
Priority: Deployment → Service → ConfigMap/Secret → Ingress → HPA
⭐⭐⭐⭐⭐ MUST KNOW

🏗️ 3. Terraform Code

AWS Provider

terraform {

  required_providers {

    aws = {

      source  = "hashicorp/aws"
      version = "~> 6.0"

    }
  }
}

provider "aws" {

  region = "ap-south-1"

}

EC2 Resource

resource "aws_instance" "web" {

  ami           = "ami-xxxxxxxx"
  instance_type = "t3.micro"

  tags = {

    Name = "web-server"

  }
}

Variable

variable "instance_type" {

  description = "EC2 instance type"

  type = string

  default = "t3.micro"
}

Output

output "instance_public_ip" {

  value = aws_instance.web.public_ip

}
Possible interview questions:

Write Terraform code to create an EC2 instance.
How do you define a variable?
How do you create an output?
⭐⭐⭐⭐⭐ MUST KNOW

🔧 4. Jenkinsfile

Basic Declarative Pipeline

pipeline {

    agent any

    stages {

        stage('Checkout') {

            steps {

                echo 'Checking out source code'

            }
        }


        stage('Build') {

            steps {

                echo 'Building application'

            }
        }


        stage('Test') {

            steps {

                echo 'Running tests'

            }
        }


        stage('Docker Build') {

            steps {

                sh 'docker build -t myapp:latest .'

            }
        }


        stage('Deploy') {

            steps {

                echo 'Deploying application'

            }
        }
    }
}
Possible question: Write a basic Jenkins declarative pipeline.
⭐⭐⭐⭐ GOOD TO KNOW

⚙️ 5. GitHub Actions YAML

name: CI

on:

  push:

    branches:
      - main


jobs:

  build:

    runs-on: ubuntu-latest

    steps:

      - name: Checkout
        uses: actions/checkout@v4


      - name: Build
        run: echo "Building application"


      - name: Test
        run: echo "Running tests"
Possible question: Write a basic GitHub Actions workflow.
⭐⭐⭐ BASIC

🐚 6. Bash Scripting

File Check

#!/bin/bash

if [ -f "/etc/passwd" ]; then

    echo "File exists"

else

    echo "File does not exist"

fi

Simple Backup Script

#!/bin/bash

SOURCE="/var/www"

BACKUP="/backup"

DATE=$(date +%Y-%m-%d)

mkdir -p "$BACKUP"

tar -czf "$BACKUP/backup-$DATE.tar.gz" "$SOURCE"

echo "Backup completed"
Basic Bash is enough unless the specific job requires strong scripting skills.
⭐⭐⭐ BASIC

☁️ 7. Important AWS CLI

Check AWS Identity

aws sts get-caller-identity

List S3 Buckets

aws s3 ls

List EKS Clusters

aws eks list-clusters

Update EKS Kubeconfig

aws eks update-kubeconfig \
  --region ap-south-1 \
  --name my-cluster
No need to memorize hundreds of AWS CLI commands. These are only the common interview-level examples.
