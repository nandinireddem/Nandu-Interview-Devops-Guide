1. Jenkins Build Is Failing

Question

A Jenkins pipeline suddenly starts failing. How would you troubleshoot it?

I would first open the console output and identify the first meaningful error. Then I would determine which stage failed:
  • Checkout
  • Build
  • Test
  • Docker build
  • Registry push
  • Deployment
I would fix the root cause and rerun the pipeline.
⭐⭐⭐⭐⭐ VERY IMPORTANT

2. Jenkins Agent Is Offline

Manage Jenkins → Nodes
I would check:
  • Agent status
  • Network connectivity
  • Jenkins agent process
  • Java version
  • Disk space
  • Authentication
  • Controller-agent connection
If the agent runs on Linux: 
df -h
free -h
java -version
⭐⭐⭐⭐⭐

3. Jenkins Job Is Stuck in Queue

I would check whether an eligible agent is available. Possible reasons:
  • No available executor
  • Agent offline
  • Label mismatch
  • Concurrency restriction
  • Resource shortage
I would inspect the queue and node configuration.
⭐⭐⭐⭐⭐ VERY IMPORTANT

4. Git Checkout Is Failing

git clone <repository-url>
I would check:
  • Repository URL
  • Branch name
  • Git credentials
  • SSH key
  • Repository permissions
  • Network connectivity
  • Git installation on the agent
I would also verify that Jenkins is using the expected credential.
⭐⭐⭐⭐⭐

5. Jenkins Cannot Authenticate to GitHub

I would verify the configured Jenkins credential and its permissions. Depending on the setup, Jenkins may use:
  • SSH key
  • Personal access token
  • GitHub App credentials
I would also check whether the credential is correctly selected in the pipeline or SCM configuration.
⭐⭐⭐⭐⭐ VERY IMPORTANT

6. Docker Command Fails Inside Jenkins

docker --version
docker ps
I would check whether Docker is installed on the Jenkins agent and whether the Jenkins user can access the Docker daemon. For Linux: 
systemctl status docker

groups jenkins
I would also verify the Docker socket and agent environment.
⭐⭐⭐⭐⭐

7. Docker Image Build Works Locally but Fails in Jenkins

I would compare the local and Jenkins environments. Check:
  • Docker version
  • Build context
  • Dockerfile
  • Environment variables
  • Credentials
  • Network access
  • File permissions
  • Architecture
The Jenkins console output should be used to identify the specific failure.
⭐⭐⭐⭐⭐ VERY IMPORTANT

8. Jenkins Cannot Push Image to Docker Hub

docker login

docker push username/myapp:latest
I would verify:
  • Docker registry credentials
  • Credential ID configured in Jenkins
  • Repository name
  • Image tag
  • Docker Hub permissions
I would avoid hardcoding the username or password in the Jenkinsfile.
⭐⭐⭐⭐⭐

9. Jenkins Cannot Push Image to Amazon ECR

I would verify AWS credentials and ECR permissions. Typical required actions include permissions related to authenticating and pushing image layers. The flow is:
Jenkins
↓
AWS Credentials
↓
ECR Login
↓
Docker Tag
↓
Docker Push
↓
Amazon ECR
⭐⭐⭐⭐⭐ VERY IMPORTANT

10. Jenkins Pipeline Is Not Triggering Automatically

I would check:
  • Webhook configuration
  • Repository webhook delivery
  • Jenkins URL accessibility
  • Job trigger configuration
  • Branch configuration
  • Webhook plugin/configuration
For GitHub integration, I would inspect the webhook delivery logs to determine whether the event reached Jenkins.
⭐⭐⭐⭐⭐

11. Jenkinsfile Has Syntax Error

I would inspect the pipeline syntax and validate the Jenkinsfile before running it. For declarative pipelines, the structure should follow: 
pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building application'
            }
        }
    }
}
I would identify the exact parser error reported by Jenkins.
⭐⭐⭐⭐⭐ VERY IMPORTANT

12. Jenkins Credentials Are Not Working

I would verify:
  • Credential exists
  • Credential ID matches Jenkinsfile
  • Credential type is correct
  • Credential has required permissions
  • Credential is available to the job
I would never print secrets directly into console output.
⭐⭐⭐⭐⭐

13. Pipeline Is Taking Too Long

I would identify the slowest stage. Possible causes:
  • Slow dependency downloads
  • Large Docker builds
  • Slow tests
  • Insufficient agent resources
  • Network latency
  • Unnecessary sequential stages
Where appropriate, independent stages can be parallelized.
⭐⭐⭐⭐⭐ VERY IMPORTANT

14. Jenkins Server Disk Is Full

df -h

du -sh /var/lib/jenkins/*
I would identify whether the space is being consumed by:
  • Old builds
  • Workspace files
  • Artifacts
  • Logs
  • Docker images
  • Temporary files
Then I would implement build retention and cleanup policies rather than manually deleting important Jenkins data.
⭐⭐⭐⭐

15. Workspace Has Corrupted or Stale Files

If a build is behaving unexpectedly because of workspace state, I would clean the workspace and rerun the build. In a Pipeline: 
cleanWs()
I would first confirm that workspace cleanup is safe for the job.
⭐⭐⭐⭐⭐ VERY IMPORTANT

16. Jenkins Deployment Stage Failed

I would determine whether the failure happened while deploying to:
  • EC2
  • Docker
  • ECS
  • Kubernetes
  • EKS
Then I would check deployment logs, credentials, connectivity, target health and the state of the deployed application.
⭐⭐⭐⭐⭐

17. Kubernetes Deployment from Jenkins Fails

kubectl get nodes
kubectl get pods
kubectl get deployment
I would verify:
  • kubectl is installed on the agent
  • Kubeconfig or cluster credentials
  • Cluster connectivity
  • Namespace
  • RBAC permissions
  • Manifest validity
  • Image availability
⭐⭐⭐⭐⭐ VERY IMPORTANT

18. Jenkins Pipeline Failed After Deployment

I would separate the problem into:
Build Successful
↓
Deployment Successful?
↓
Application Healthy?
↓
Health Check
↓
Rollback if Required
A deployment being technically successful does not necessarily mean the application is healthy.
⭐⭐⭐⭐⭐

19. How Do You Secure Jenkins?

I would use:
  • RBAC / least privilege
  • Credentials Manager
  • HTTPS
  • Restricted agent permissions
  • Plugin updates
  • Jenkins updates
  • Secret masking
  • Network restrictions
  • Audit logs
  • Separate production access
I would avoid storing passwords or cloud credentials directly inside Jenkinsfiles.
⭐⭐⭐⭐⭐ VERY IMPORTANT

21. Jenkins Troubleshooting Cheat Sheet

Problem First Check
Build failed Console output → first meaningful error
Agent offline Node → network → Java → disk
Job stuck Queue → executor → labels
Git failure URL → branch → credentials
Docker failure Docker installation → permissions
Registry push failure Login → credentials → tag → permissions
Webhook failure Webhook → Jenkins trigger → delivery
Credentials failure ID → type → permissions
Slow pipeline Identify slowest stage
Disk full df → Jenkins home → retention
Kubernetes deploy failure kubectl → kubeconfig → RBAC → namespace

🧠 Golden Jenkins Interview Formula

Build Failure → Console Output

Agent Problem → Node + Network + Resources

Git Problem → URL + Branch + Credentials

Docker Problem → Docker + Permissions + Registry

Deployment Problem → Credentials + Target + Health

Security → RBAC + Credentials + Least Privilege

Production → Build → Test → Scan → Deploy → Verify
