QUESTION 01

What is Cloud Computing?

⭐⭐⭐⭐⭐ MUST KNOW

Cloud computing means delivering computing resources such as servers, storage, databases, networking and software over the internet on demand. Instead of buying and maintaining physical infrastructure, organizations can consume cloud resources whenever they need them.

💡 Simple Example

Suppose a company needs a server for its application. Traditional approach:

Buy physical server → Install it → Maintain hardware → Pay for unused capacity.

Cloud approach:

Create an EC2 instance → Deploy application → Scale when needed → Pay according to usage.

🎤 Interview Answer

"Cloud computing is the on-demand delivery of computing resources such as compute, storage, networking and databases over the internet, allowing organizations to provision resources quickly without managing the underlying physical infrastructure."

QUESTION 02

Why do companies use Cloud Computing?

⭐⭐⭐⭐⭐ VERY COMMON

The main reason is that cloud allows organizations to provision infrastructure quickly and scale resources according to workload. Important benefits include:

→ On-demand resources
→ Scalability
→ Elasticity
→ High availability
→ Global reach
→ Reduced infrastructure management
→ Pay-as-you-go pricing models

🔥 Real-Time Example

An e-commerce application may have normal traffic on weekdays but extremely high traffic during a festival sale. Cloud infrastructure can scale according to demand.

🎤 Interview Answer

"Companies use cloud computing because it provides on-demand infrastructure, scalability, elasticity, high availability and global deployment while reducing the need to manage physical hardware."

QUESTION 03

What are the different Cloud Service Models?

⭐⭐⭐⭐⭐ MUST KNOW

The three major cloud service models are:

IaaS — Infrastructure as a Service
PaaS — Platform as a Service
SaaS — Software as a Service

IaaS → You manage more infrastructure

PaaS → Cloud manages the platform

SaaS → You mainly consume the application
QUESTION 04

What is IaaS?

⭐⭐⭐⭐⭐

IaaS stands for Infrastructure as a Service. The cloud provider provides infrastructure resources such as virtual machines, storage and networking. The customer has more control over the operating system and software stack.

💡 AWS Example

Amazon EC2 is a common example of IaaS. You choose the instance type, operating system, networking, storage and install your required software.

🎤 Interview Answer

"IaaS provides infrastructure resources such as compute, storage and networking. The customer manages the operating system and applications while the cloud provider manages the underlying physical infrastructure."

QUESTION 05

What is PaaS?

⭐⭐⭐⭐⭐

PaaS stands for Platform as a Service. The cloud provider manages the underlying infrastructure and platform components, allowing developers to focus more on the application.

💡 Simple Example

Instead of creating a server, installing the operating system and configuring the runtime yourself, a PaaS service can provide the application platform and manage much of the infrastructure for you.

🎤 Interview Answer

"PaaS provides a managed application platform where the cloud provider handles much of the infrastructure and platform management, allowing developers to focus mainly on application development and deployment."

QUESTION 06

What is SaaS?

⭐⭐⭐⭐⭐

SaaS stands for Software as a Service. The complete application is provided as a service over the internet. The customer generally consumes the application instead of managing its underlying infrastructure.

💡 Examples

Email services, online collaboration applications and CRM software can be delivered as SaaS.

🎤 Interview Answer

"SaaS is a cloud service model where a complete software application is delivered to users over the internet, while the provider manages the underlying infrastructure and application platform."

QUESTION 07

What is the difference between IaaS, PaaS and SaaS?

⭐⭐⭐⭐⭐ VERY COMMON
IaaS → More infrastructure control.

PaaS → Focus on application development.

SaaS → Consume ready-to-use software.
🧠 Easy Memory

IaaS → "Give me infrastructure."
PaaS → "Give me a platform."
SaaS → "Give me the software."

🎤 Interview Answer

"IaaS gives customers infrastructure resources with greater control. PaaS provides a managed platform for application development and deployment. SaaS provides a complete application that users consume over the internet."

QUESTION 08

What are the Cloud Deployment Models?

⭐⭐⭐⭐⭐ MUST KNOW

The commonly discussed deployment models are:

→ Public Cloud
→ Private Cloud
→ Hybrid Cloud
→ Community Cloud

QUESTION 09

What is Public Cloud?

⭐⭐⭐⭐

In a public cloud, cloud infrastructure is provided by a cloud provider and resources are delivered to customers over the provider's platform.

💡 Examples

AWS, Microsoft Azure and Google Cloud provide public cloud services.

QUESTION 10

What is Private Cloud?

⭐⭐⭐

A private cloud environment is dedicated to a single organization. It can provide greater control over the environment and may be operated by the organization or a service provider.

QUESTION 11

What is Hybrid Cloud?

⭐⭐⭐⭐⭐ VERY COMMON

Hybrid cloud combines private infrastructure with public cloud resources and allows workloads or data to operate across both environments.

🔥 Real-Time Example

A company keeps sensitive workloads in its private environment while using AWS for scalable application infrastructure.

🎤 Interview Answer

"Hybrid cloud is an architecture that combines private infrastructure with public cloud services. Organizations may use it when they need a combination of control, compliance, integration or public-cloud scalability."

⭐⭐⭐⭐ High Priority

QUESTION 12

What is Scalability?

⭐⭐⭐⭐⭐ VERY COMMON

Scalability is the ability of a system to handle increased workload by increasing its resources or capacity.

💡 Example

If an application needs more CPU or additional servers because traffic increases, scaling the infrastructure allows the application to handle the additional workload.

Vertical Scaling
Increase the capacity of an existing resource.

Horizontal Scaling
Add more instances/resources.
QUESTION 13

What is Vertical Scaling?

⭐⭐⭐⭐

Vertical scaling means increasing the capacity of an existing server or resource.

Example

EC2:

t3.medium → larger instance type

The same server becomes more powerful.

QUESTION 14

What is Horizontal Scaling?

⭐⭐⭐⭐⭐

Horizontal scaling means adding or removing multiple instances or resources to handle workload.

Example

1 EC2 instance
↓
3 EC2 instances
↓
Load Balancer distributes traffic.

🎤 Interview Answer

"Horizontal scaling increases capacity by adding more instances, while vertical scaling increases the capacity of an existing instance."

QUESTION 15

What is Elasticity?

⭐⭐⭐⭐⭐ VERY COMMON

Elasticity is the ability of a cloud environment to automatically increase or decrease resources according to workload demand.

Low Traffic → Fewer Resources → Traffic Increases → More Resources → Traffic Decreases → Scale Down
Memory Trick:

Scalability = ability to handle growth.
Elasticity = dynamically adjust resources according to demand.
QUESTION 16

What is the difference between Scalability and Elasticity?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
Example

A system is designed to support more users by adding infrastructure → Scalability.

The infrastructure automatically adds resources during peak traffic and removes them after traffic decreases → Elasticity.

🎤 Interview Answer

"Scalability refers to the ability of a system to handle increased workload by increasing capacity. Elasticity goes one step further by dynamically adding or removing resources based on current demand."

QUESTION 17

What is High Availability?

⭐⭐⭐⭐⭐

High availability means designing systems so that they remain available and continue serving users even when some components fail.

🔥 AWS Example

Deploy application instances across multiple Availability Zones and use a load balancer to distribute traffic.

QUESTION 18

What is Fault Tolerance?

⭐⭐⭐⭐

Fault tolerance means the system can continue operating even when one or more components fail.

High Availability → Reduce downtime and remain available.

Fault Tolerance → Continue operation despite failures.
QUESTION 19

What is an AWS Region?

⭐⭐⭐⭐⭐ MUST KNOW

An AWS Region is a separate geographic area containing multiple Availability Zones.

Example

Mumbai region:
ap-south-1

A region contains multiple Availability Zones that are isolated from each other.

QUESTION 20

What is an Availability Zone?

⭐⭐⭐⭐⭐ MUST KNOW

An Availability Zone, or AZ, is one or more discrete data centers within an AWS Region, designed with independent infrastructure to provide isolation and resilience.

AWS Region ↓ Availability Zone A Availability Zone B Availability Zone C
🎤 Interview Answer

"An Availability Zone is an isolated location within an AWS Region. Deploying workloads across multiple Availability Zones helps improve availability and resilience."

QUESTION 21

Why do we deploy applications across multiple Availability Zones?

⭐⭐⭐⭐⭐

To improve availability and reduce the impact of an Availability Zone failure.

🔥 Example

If an application runs only in AZ-A and that AZ experiences an issue, the application may become unavailable. If workloads are distributed across AZ-A and AZ-B, traffic can continue through healthy infrastructure.

⭐⭐⭐ Medium Priority

QUESTION 22

What is the difference between Region and Availability Zone?

⭐⭐⭐
Region = Geographic area.

Availability Zone = Isolated location within a Region.
Memory Trick

Region = City/Geographic area
AZ = Separate infrastructure location inside that region

QUESTION 23

What is Multi-Region Architecture?

⭐⭐⭐

Multi-Region architecture means deploying workloads across multiple AWS Regions. It can be used for disaster recovery, business continuity, latency optimization or geographic requirements.

QUESTION 24

What is Disaster Recovery?

⭐⭐⭐⭐

Disaster Recovery is the process and architecture used to restore applications and data after a major failure or disaster.

🔥 Example

If the primary environment becomes unavailable, a company may restore the application using backups or a secondary environment.

QUESTION 25

What is Pay-as-you-go?

⭐⭐⭐⭐

Pay-as-you-go means customers generally pay for the cloud resources they consume rather than purchasing all physical infrastructure upfront.

Example

If you launch an EC2 instance for a workload, charges are based on the applicable pricing model and usage.

⭐⭐ Less Frequently Asked

QUESTION 26

What is Community Cloud?

⭐⭐

A community cloud is designed for organizations that share common requirements such as regulatory, security or operational needs.

QUESTION 27

What is Multi-Cloud?

⭐⭐⭐

Multi-cloud means using services from more than one cloud provider.

Example

An organization may use AWS for infrastructure, Azure for specific enterprise services and Google Cloud for particular data or analytics workloads.

QUESTION 28

What is Vendor Lock-in?

⭐⭐⭐

Vendor lock-in occurs when it becomes difficult or expensive to move workloads from one cloud provider or technology to another.

Example

An application heavily dependent on provider-specific services may require significant redesign before it can be moved to another cloud.

🎯 Real-Time Interview Scenarios

SCENARIO 01

Your application receives 10x normal traffic during a sale. What will you do?

⭐⭐⭐⭐⭐

I would design the application for horizontal scaling and use load balancing and Auto Scaling where appropriate.

Traffic Increase → Load Balancer → Auto Scaling → More Instances
🎤 Strong Answer

"I would use a scalable architecture with a load balancer and horizontal scaling. Auto Scaling can add instances when demand increases and remove them when demand decreases. This provides elasticity and avoids depending on a single server."

SCENARIO 02

One Availability Zone goes down. How can the application remain available?

⭐⭐⭐⭐⭐

Deploy the application across multiple Availability Zones and ensure traffic can be routed to healthy resources.

User ↓ Load Balancer ↓ AZ-A + AZ-B ↓ Healthy Application Instances
SCENARIO 03

How would you design a highly available web application on AWS?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

A common architecture would include:

→ VPC
→ Public/private subnet design
→ Load Balancer
→ EC2 Auto Scaling
→ Multiple Availability Zones
→ Database with an appropriate HA architecture
→ Monitoring
→ Backup and recovery strategy

Users ↓ Load Balancer ↓ AZ-A ←→ AZ-B ↓ Application Instances ↓ Database
SCENARIO 04

Why would you choose Multi-AZ instead of Multi-Region?

⭐⭐⭐⭐

For many workloads, Multi-AZ provides strong availability and resilience within a region. Multi-Region is considered when requirements include regional disaster recovery, geographic distribution or global latency needs.

🎤 Interview Answer

"I would choose based on the requirement. Multi-AZ is commonly used for high availability within a region, while Multi-Region can provide additional resilience against regional failures and can also support geographic distribution."
