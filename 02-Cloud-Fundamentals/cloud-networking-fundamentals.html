QUESTION 01

What is Computer Networking?

⭐⭐⭐⭐⭐ MUST KNOW

Computer networking is the process of connecting computers, servers, applications and other devices so that they can communicate and exchange data. In cloud environments, networking allows users, applications, services and databases to communicate securely.

💡 Simple Example

A user opens a website.

User ↓ Internet ↓ Load Balancer ↓ Application Server ↓ Database

Networking allows communication between these different components.

🎤 Interview Answer

"Computer networking is the communication between connected devices and systems using defined protocols and addressing mechanisms. In cloud environments, networking enables secure communication between users, applications and services."

QUESTION 02

What is an IP Address?

⭐⭐⭐⭐⭐ MUST KNOW

An IP address is a logical address assigned to a network interface or device so that it can be identified and communicate over a network. There are two major IP versions:

→ IPv4
→ IPv6

💡 IPv4 Example

192.168.1.10

A server can use an IP address to communicate with other systems on the network.

🎤 Interview Answer

"An IP address is a logical network address used to identify a network interface and enable communication between systems."

QUESTION 03

What is the difference between Public IP and Private IP?

⭐⭐⭐⭐⭐ VERY COMMON
Public IP Private IP
Used for communication over the public internet Used inside private networks
Must be globally unique within its scope Can be reused in different private networks
Used when direct public connectivity is required Commonly used for internal communication
🔥 Cloud Example

Web server: Public-facing load balancer may have public connectivity.

Database: Uses private connectivity and should generally not be directly exposed to the public internet.

🎤 Interview Answer

"A public IP is used for public network communication, while a private IP is used for communication within a private network. In a secure cloud architecture, internal services such as databases are commonly accessed using private networking."

QUESTION 04

What is a subnet?

⭐⭐⭐⭐⭐ MUST KNOW

A subnet is a logical subdivision of an IP network. Subnets help organize resources and control how network traffic flows within a larger network.

🔥 Cloud Example

A VPC can be divided into multiple subnets.

Public Subnet → Load Balancer

Private Subnet → Application Servers

Private Subnet → Database

🎤 Interview Answer

"A subnet is a logical subdivision of an IP network. In cloud architectures, subnets are commonly used to organize resources and separate public-facing and internal workloads."

QUESTION 05

What is a CIDR block?

⭐⭐⭐⭐⭐ MUST KNOW

CIDR stands for Classless Inter-Domain Routing. It is a notation used to represent a range of IP addresses.

💡 Example

10.0.0.0/16

The /16 represents the network prefix length.

Smaller prefix length → generally larger address range.
Larger prefix length → generally smaller address range.

🎤 Interview Answer

"CIDR is a notation used to define IP address ranges using a network prefix length, such as 10.0.0.0/16."

QUESTION 06

What is DNS?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE

DNS stands for Domain Name System. DNS translates human-readable domain names into IP addresses that systems can use to communicate.

User ↓ [www.example.com](http://www.example.com) ↓ DNS ↓ IP Address ↓ Web Server
💡 Simple Example

Humans prefer:
google.com

Computers communicate using network addresses such as IP addresses. DNS provides the mapping between the domain name and the appropriate address.

🎤 Interview Answer

"DNS is a naming system that translates domain names into network addresses, allowing users to access services using human-readable names instead of IP addresses."

QUESTION 07

What is a Port?

⭐⭐⭐⭐⭐ MUST KNOW

A port is a logical communication endpoint used by networked applications and services. Different services commonly listen on different port numbers.

Port Common Usage
22 SSH
80 HTTP
443 HTTPS
53 DNS
3306 MySQL
5432 PostgreSQL
🎤 Interview Answer

"A port is a logical endpoint used to identify a specific network service or application on a host."

QUESTION 08

What is HTTP vs HTTPS?

⭐⭐⭐⭐⭐ VERY COMMON
HTTP HTTPS
Hypertext Transfer Protocol HTTP Secure
Normally uses port 80 Normally uses port 443
Traffic is not protected by TLS Uses TLS to protect communication
🎤 Interview Answer

"HTTP is the standard protocol for transferring web data, typically over port 80. HTTPS uses HTTP over TLS to provide encrypted and authenticated communication, typically over port 443."

QUESTION 09

What is TCP vs UDP?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
TCP UDP
Connection-oriented Connectionless
Reliable delivery No built-in delivery guarantee
Maintains ordering Does not provide TCP-style ordering
More overhead Lower overhead
💡 Simple Understanding

TCP: "Make sure the data reaches correctly."

UDP: "Send the data quickly without establishing the same type of connection and reliability mechanism."

🎤 Interview Answer

"TCP is connection-oriented and provides reliable, ordered delivery, while UDP is connectionless and provides lower overhead without TCP's built-in reliability and ordering mechanisms."

QUESTION 10

What is a Router?

⭐⭐⭐⭐⭐

A router is a network device or function that forwards packets between different networks based on routing information. In cloud environments, routing tables determine how traffic should move between network destinations.

Source ↓ Router / Routing Table ↓ Destination Network
🎤 Interview Answer

"A router forwards network traffic between different networks based on routing information. In cloud environments, routing tables determine where packets should be sent."

QUESTION 11

What is a Firewall?

⭐⭐⭐⭐⭐ MUST KNOW

A firewall is a security control that filters network traffic according to defined rules. Rules may determine which traffic is allowed or denied based on factors such as source, destination, protocol and port.

🔥 Example

Allow: → HTTPS traffic to the web application.

Restrict: → Direct database access from the public internet.

🎤 Interview Answer

"A firewall controls network traffic by applying security rules that allow or deny communication based on defined criteria."

⭐⭐⭐⭐ High Priority

QUESTION 12

What is a Load Balancer?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

A load balancer distributes incoming traffic across multiple healthy backend resources. It helps improve availability, scalability and reliability.

Users ↓ Load Balancer ↙ ↓ ↘ Server 1 Server 2 Server 3
🔥 Real-Time Example

Suppose one server cannot handle all requests. Instead of sending every request to one server, a load balancer distributes requests across multiple healthy servers.

🎤 Interview Answer

"A load balancer distributes incoming traffic across multiple backend resources, improving availability and allowing the application to scale horizontally."

QUESTION 13

What is NAT?

⭐⭐⭐⭐

NAT stands for Network Address Translation. It allows private network resources to communicate with external networks by translating network addresses. In AWS, a NAT Gateway is commonly used to allow resources in private subnets to initiate outbound internet connections without making those resources directly publicly reachable.

Private EC2 ↓ Private Subnet ↓ NAT Gateway ↓ Internet
🎤 Interview Answer

"NAT allows private resources to communicate with external networks without requiring those resources to have direct public internet exposure. In AWS, a NAT Gateway is commonly used for outbound internet access from private subnets."

QUESTION 14

What is a VPN?

⭐⭐⭐⭐

VPN stands for Virtual Private Network. It creates a secure communication path over an untrusted or public network.

💡 Example

A company has an on-premises data center and an AWS VPC. A VPN connection can provide encrypted connectivity between the two environments over the internet.

QUESTION 15

What is a private network?

⭐⭐⭐⭐

A private network is a network environment intended for internal communication and not directly exposed to the public internet. Private networking is commonly used for backend services, databases and internal applications.

QUESTION 16

What is the difference between public and private subnet?

⭐⭐⭐⭐⭐
Public Subnet Private Subnet
Has a route that provides a path to an Internet Gateway Does not have a direct route to an Internet Gateway
Can contain internet-facing resources when appropriately configured Common for internal resources
Example: public load balancer Example: database / internal application
🧠 Important

A subnet is considered public when its routing provides a path to an Internet Gateway. A public IP alone does not by itself define the subnet as public.
QUESTION 17

What is an Internet Gateway?

⭐⭐⭐⭐

An Internet Gateway is an AWS VPC component that provides a path for communication between resources in a VPC and the public internet when the routing and addressing configuration allow it.

Public Subnet ↓ Route Table ↓ Internet Gateway ↓ Internet

⭐⭐⭐ Medium Priority

QUESTION 18

What is a routing table?

⭐⭐⭐

A routing table contains rules that determine where network traffic should be sent based on the destination address.

💡 Example

Destination: 0.0.0.0/0
Target: Internet Gateway

This represents a default route toward the internet gateway.

QUESTION 19

What is latency?

⭐⭐⭐

Latency is the time taken for data to travel between a source and destination. Lower latency generally means faster response times.

🔥 Cloud Example

If users are located in India, choosing infrastructure closer to those users can reduce network latency compared with placing the same workload much farther away.

QUESTION 20

What is bandwidth?

⭐⭐⭐

Bandwidth refers to the amount of data that can be transferred over a network connection within a given period.

🧠 Easy Memory

Latency → How long does it take?
Bandwidth → How much data can be transferred?
QUESTION 21

What is a network protocol?

⭐⭐⭐

A network protocol is a defined set of rules that systems use to communicate with each other.

Examples

HTTP → Web communication
HTTPS → Secure web communication
TCP → Reliable transport
UDP → Connectionless transport
DNS → Name resolution
SSH → Secure remote administration

⭐⭐ Less Frequently Asked

QUESTION 22

What is packet loss?

⭐⭐

Packet loss occurs when network packets fail to reach their destination. It can result in retransmissions, degraded performance, timeouts or application errors depending on the protocol and application.

QUESTION 23

What is a MAC address?

⭐⭐

A MAC address is a hardware-level network identifier associated with a network interface. It operates at the data-link layer and is different from an IP address.

🎯 Real-Time Interview Scenarios

SCENARIO 01

Your EC2 instance cannot access the internet. How will you troubleshoot it?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

I would troubleshoot the network path step by step instead of randomly changing security rules.

EC2 ↓ Subnet ↓ Route Table ↓ NAT / Internet Gateway ↓ Internet

Check:

→ Is the instance in the correct subnet?
→ Does the route table contain the required route?
→ If private subnet, is NAT configured correctly?
→ If public subnet, is an Internet Gateway attached and routed?
→ Are Security Group rules allowing required traffic?
→ Are Network ACL rules allowing traffic?
→ Is DNS resolution configured correctly if the issue is domain-based?

🎤 Strong Answer

"I would troubleshoot from the instance outward: verify the subnet and route table, then check the NAT Gateway or Internet Gateway depending on the architecture, followed by Security Group and NACL rules, DNS configuration and the destination itself."

SCENARIO 02

The application server can reach the internet, but users cannot reach the application. What could be wrong?

⭐⭐⭐⭐⭐

The outbound path working does not guarantee inbound public connectivity. I would check:

→ Load balancer / public endpoint
→ Public IP or DNS configuration
→ Route table
→ Internet Gateway path
→ Security Group inbound rules
→ NACL rules
→ Application listening port

SCENARIO 03

Your application can reach the EC2 server, but cannot connect to MySQL. How do you troubleshoot?

⭐⭐⭐⭐⭐
Application Server ↓ Security Group ↓ Network Path ↓ Database Security Group ↓ MySQL : 3306 ↓ Database

I would verify:

→ Database is running
→ Application uses correct database endpoint
→ Port 3306 is listening
→ Database Security Group allows port 3306 from the application security group or appropriate source
→ NACL rules
→ Routing
→ Credentials and database configuration

🎤 Strong Answer

"I would first confirm the database is healthy and listening on the expected port. Then I would verify the network path, routing, database Security Group rules, NACLs and finally the application credentials and connection configuration."

SCENARIO 04

How would you design a secure three-tier cloud network?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE
🌍 Internet ↓ Public Load Balancer ↓ Private Application Subnet ↓ Private Database Subnet

Security Groups * Routing * NACLs * IAM * Encryption
🎤 Strong Answer

"I would place only the required internet-facing component in the public layer, keep application and database workloads in private subnets, control traffic between tiers using security groups, use appropriate routing and network controls, and protect sensitive data with encryption."

SCENARIO 05

Why should a database usually not be placed directly in a public subnet?

⭐⭐⭐⭐⭐

A database usually does not need direct internet access. Keeping it private reduces its public attack surface and allows access to be restricted to trusted application components.

🎤 Answer

"I would normally keep the database in private subnets because it does not require direct internet exposure. Application servers can communicate with it through controlled private network paths and security-group rules."
