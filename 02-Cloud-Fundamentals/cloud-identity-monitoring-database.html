⭐⭐⭐⭐⭐ Shared Responsibility

QUESTION 01

What is the Shared Responsibility Model?

⭐⭐⭐⭐⭐ MUST KNOW

The Shared Responsibility Model defines which security responsibilities are handled by the cloud provider and which responsibilities remain with the customer.

Cloud Provider
↓ Security OF the Cloud

Customer
↓ Security IN the Cloud
💡 Simple Example

The cloud provider is responsible for physical data centers, physical networking and underlying infrastructure. The customer is responsible for things such as data, identities, permissions and configuration according to the service being used.

🎤 Interview Answer

"The Shared Responsibility Model defines how security responsibilities are divided between the cloud provider and the customer. The provider is responsible for security of the underlying cloud infrastructure, while the customer remains responsible for security and configuration within the cloud according to the services they use."

QUESTION 02

What does the cloud provider manage?

⭐⭐⭐⭐⭐

The provider generally manages the underlying physical and cloud infrastructure, including data centers, physical hardware, networking infrastructure and foundational services.

🎤 Interview Answer

"The provider manages the physical infrastructure and the security of the underlying cloud environment, including data centers, hardware and foundational infrastructure."

QUESTION 03

What does the customer manage?

⭐⭐⭐⭐⭐

Customer responsibilities depend on the service, but can include data, identities, access permissions, application configuration, operating systems for some services, network configuration and security settings.

🔥 EC2 Example

AWS manages the physical server and underlying infrastructure. The customer manages the guest operating system, installed software, IAM permissions, security configuration and application data.

QUESTION 04

Does the cloud provider secure everything automatically?

⭐⭐⭐⭐⭐ INTERVIEW TRICK QUESTION

No. Using a cloud provider does not remove the customer's security responsibilities. Incorrect IAM permissions, exposed storage, weak credentials, insecure applications or misconfigured resources can still create security risks.

🎤 Strong Answer

"No. Cloud security is a shared responsibility. The provider secures the underlying cloud infrastructure, but the customer must securely configure identities, permissions, data and resources according to the service."

⭐⭐⭐⭐⭐ Cloud Identity & IAM

QUESTION 05

What is IAM?

⭐⭐⭐⭐⭐ MUST KNOW

IAM stands for Identity and Access Management. IAM controls:

→ Who can access resources
→ What they can access
→ What actions they can perform

Identity
↓ Authentication
↓ Authorization
↓ Resource Access
💡 Example

A DevOps engineer may be allowed to read logs and deploy applications but may not be allowed to delete production databases.

🎤 Interview Answer

"IAM is used to manage identities and control access to cloud resources. It determines who can access a resource and what actions that identity is allowed to perform."

QUESTION 06

What is Authentication?

⭐⭐⭐⭐⭐

Authentication verifies the identity of a user, application or system.

💡 Simple Example

Username + password, MFA or another identity mechanism is used to prove who you are.

🧠 Memory Trick

Authentication → Who are you?
Authorization → What are you allowed to do?
QUESTION 07

What is Authorization?

⭐⭐⭐⭐⭐

Authorization determines what an authenticated identity is allowed to access or perform.

💡 Example

A user successfully logs in. Authentication → User is verified. Authorization → User is allowed to read an S3 bucket but not delete objects.

QUESTION 08

Authentication vs Authorization?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
Authentication Authorization
Verifies identity Determines permissions
Who are you? What can you do?
Login / MFA Policies / Permissions
🎤 Interview Answer

"Authentication verifies who the user is, while authorization determines what that authenticated user is allowed to access or perform."

QUESTION 09

What is the Principle of Least Privilege?

⭐⭐⭐⭐⭐ VERY COMMON

Least privilege means giving an identity only the permissions required to perform its job and no unnecessary permissions.

🔥 Example

A monitoring application only needs permission to read metrics. It does NOT need permission to terminate EC2 instances.

🎤 Interview Answer

"Least privilege means granting only the minimum permissions required to perform a task. It reduces the impact of accidental or unauthorized actions."

QUESTION 10

Why is MFA important?

⭐⭐⭐⭐⭐

MFA, or Multi-Factor Authentication, adds an additional verification factor beyond a password.

💡 Example

Password + authenticator code. Even if the password is compromised, the attacker may still need the second factor.

QUESTION 11

What is a cloud IAM policy?

⭐⭐⭐⭐⭐

An IAM policy is a set of permissions that defines which actions are allowed or denied on specified resources under defined conditions.

💡 Example

Allow:
→ Read objects from a specific storage location. Deny:
→ Delete objects.

⭐⭐⭐⭐⭐ Cloud Monitoring & Logging

QUESTION 12

What is Cloud Monitoring?

⭐⭐⭐⭐⭐ MUST KNOW

Cloud monitoring is the process of collecting and observing metrics and health information from cloud resources and applications.

🔥 Example

Monitor:
→ CPU utilization
→ Memory
→ Network traffic
→ Request count
→ Error rate
→ Latency

🎤 Interview Answer

"Cloud monitoring collects and analyzes metrics and health information from infrastructure and applications so that teams can detect problems, understand performance and take corrective actions."

QUESTION 13

What is logging?

⭐⭐⭐⭐⭐

Logging records events and activities generated by systems, applications and infrastructure.

💡 Example

Application logs may contain:
→ Request information
→ Errors
→ Authentication events
→ Application events

QUESTION 14

Monitoring vs Logging?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
Monitoring Logging
Observes metrics and health Records events and messages
CPU = 90% Application error message
Helps identify performance problems Helps investigate events and failures
🎤 Interview Answer

"Monitoring focuses mainly on metrics and system health, while logging records detailed events and messages. Monitoring can tell me that something is wrong, while logs often help me understand what happened."

QUESTION 15

What is an alert?

⭐⭐⭐⭐

An alert is a notification generated when a defined condition or threshold is met.

🔥 Example

CPU utilization > 80% ↓ Monitoring detects threshold ↓ Alert ↓ DevOps engineer investigates

QUESTION 16

Why is monitoring important in DevOps?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

Monitoring helps DevOps teams detect failures, identify performance bottlenecks, understand system behavior and respond to incidents.

🎤 Interview Answer

"Monitoring is important in DevOps because it provides visibility into infrastructure and applications. It helps teams detect issues early, troubleshoot incidents, measure performance and improve reliability."

⭐⭐⭐⭐⭐ Cloud Database Fundamentals

QUESTION 17

What is a cloud database?

⭐⭐⭐⭐⭐ MUST KNOW

A cloud database is a database service hosted or managed within a cloud environment.

Cloud databases can be relational or non-relational depending on application requirements.

🎤 Interview Answer

"A cloud database is a database service provided or hosted in a cloud environment. Depending on the workload, organizations can choose relational or non-relational database technologies."

QUESTION 18

What is a relational database?

⭐⭐⭐⭐⭐ VERY COMMON

A relational database stores structured data in tables made up of rows and columns and typically uses SQL for querying and managing data.

💡 Example

Customers table:

ID | Name | Email
1 | Nandu | nandu@example.com

🎤 Interview Answer

"A relational database stores structured data in tables with rows and columns and commonly uses SQL. It is suitable for workloads that require structured relationships and transactional consistency."

QUESTION 19

What is a NoSQL database?

⭐⭐⭐⭐⭐

NoSQL databases are non-relational databases designed for flexible data models and large-scale distributed workloads. Different NoSQL systems use models such as key-value, document, column-family or graph.

💡 Example

A user profile can be represented as a document containing different attributes without requiring a fixed relational table structure.

🎤 Interview Answer

"NoSQL databases are non-relational databases designed for flexible data models and scalable distributed workloads. They are useful when the application does not require a traditional relational table structure."

QUESTION 20

SQL vs NoSQL — What is the difference?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
SQL / Relational NoSQL
Tables and relationships Flexible data models
Structured schema Often flexible schema
SQL queries Database-specific query models
Strong fit for relational transactions Strong fit for many distributed/flexible workloads
🎤 Interview Answer

"Relational databases organize structured data into related tables and use SQL, while NoSQL databases provide flexible data models and are commonly used for horizontally scalable distributed workloads. The choice depends on application requirements."

QUESTION 21

What is a primary key?

⭐⭐⭐⭐

A primary key uniquely identifies each record in a relational table.

💡 Example

Customer ID can uniquely identify each customer.

QUESTION 22

What is a database transaction?

⭐⭐⭐⭐

A transaction is a logical unit of database work that should be processed according to the database's consistency and transaction rules.

🔥 Banking Example

Transfer ₹1,000:

Debit Account A ↓ Credit Account B

The transaction should not leave the system in an incorrect partial state.

QUESTION 23

What is a managed database service?

⭐⭐⭐⭐⭐

A managed database service is a cloud database offering where the provider handles many operational tasks such as infrastructure provisioning, maintenance and certain backup or patching operations depending on the service.

🔥 AWS Example

Amazon RDS is a managed relational database service. The provider handles many infrastructure-level operational tasks, while the customer still manages database configuration, data, access and other responsibilities depending on the service.

🎤 Interview Answer

"A managed database service reduces operational overhead by having the cloud provider manage much of the underlying infrastructure and database operations. The exact division of responsibility depends on the service."

🎯 Real-Time Interview Scenarios

SCENARIO 01

A developer needs access only to read application logs. What permissions would you give?

⭐⭐⭐⭐⭐ LEAST PRIVILEGE

I would create or use an identity with only the required read-only permissions for the relevant logging resources.

🎤 Strong Answer

"I would follow least privilege and provide only the read permissions required for the relevant logs. I would avoid granting write, administrative or resource-deletion permissions because they are not required for the developer's task."

SCENARIO 02

An application suddenly becomes slow. How would monitoring help?

⭐⭐⭐⭐⭐

I would check relevant metrics such as CPU, memory, network, request count, latency, error rate and database performance. Then I would correlate the metrics with logs to identify the root cause.

User Reports Slowness ↓ Monitoring Metrics ↓ Identify Abnormal Metric ↓ Application Logs ↓ Root Cause ↓ Fix / Scale / Optimize
SCENARIO 03

A company needs strong relationships between customer, order and payment data. Which database type would you consider?

⭐⭐⭐⭐⭐

A relational database would generally be a strong candidate because the data has structured relationships and transactional requirements.

🎤 Answer

"I would consider a relational database because customer, order and payment information has structured relationships and may require transactional consistency."

SCENARIO 04

An application has highly variable traffic and needs a highly scalable data store with a flexible data model. What would you consider?

⭐⭐⭐⭐

Depending on the workload, a NoSQL database could be considered because many NoSQL systems are designed for distributed, horizontally scalable workloads and flexible data models.

🎤 Answer

"I would evaluate a NoSQL database if the application requires a flexible data model and large-scale distributed access. I would still make the final choice based on consistency, access patterns, query requirements and workload characteristics."

SCENARIO 05

A cloud storage resource was accidentally made publicly accessible. Whose responsibility is that?

⭐⭐⭐⭐⭐ SHARED RESPONSIBILITY

The exact responsibility depends on the service, but incorrect resource permissions and configuration are generally customer responsibilities.

🎤 Strong Answer

"Under the Shared Responsibility Model, the provider secures the underlying cloud infrastructure, while the customer is responsible for securely configuring resources, identities and access permissions. Therefore, an incorrectly configured public storage resource is generally a customer-side configuration issue."
