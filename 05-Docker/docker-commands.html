Docker Commands

Essential Docker commands for images, containers, logs, execution, inspection, networking, cleanup and real-world DevOps troubleshooting.

⭐⭐⭐⭐⭐ DOCKER COMMANDS — MUST KNOW

You do not need to memorize every Docker command for an interview. Focus on the commands used daily for building, running, inspecting, troubleshooting and cleaning Docker workloads.

⭐⭐⭐⭐⭐ 1. Docker Version & Information

Check Docker version

docker --version

docker version

docker --version gives the CLI version, while docker version provides client and server/daemon details.

System information

docker info
docker info is useful when troubleshooting the Docker environment because it provides information about the daemon, containers, images, storage driver and runtime configuration.

⭐⭐⭐⭐⭐ 2. Working with Docker Images

List images

docker images

docker image ls

Pull an image

docker pull nginx

docker pull nginx:latest

Remove an image

docker rmi nginx

docker image rm nginx

Inspect an image

docker image inspect nginx

View image history

docker history nginx

Tag an image

docker tag myapp:latest username/myapp:1.0
Interview point:

Image commands are commonly used to inspect, version, tag, pull, push and remove application images.

⭐⭐⭐⭐⭐ 3. docker run

Basic command

docker run nginx

Run in background

docker run -d nginx

-d runs the container in detached mode.

Assign a name

docker run -d --name web nginx

Publish a port

docker run -d --name web -p 8080:80 nginx

Set environment variable

docker run -d \
--name app \
-e APP_ENV=production \
myapp:1.0

Run interactively

docker run -it ubuntu bash
docker run creates and starts a new container from an image. It can also configure the container's name, ports, environment variables, volumes, network and command.

⭐⭐⭐⭐⭐ 4. List Containers

Running containers

docker ps

All containers

docker ps -a

Only container IDs

docker ps -q

All container IDs

docker ps -aq
Command Purpose
docker ps Shows running containers
docker ps -a Shows running and stopped containers
docker ps -q Shows IDs of running containers

⭐⭐⭐⭐⭐ 5. Container Lifecycle

Command Purpose
docker create Create a container without starting it
docker start Start a stopped container
docker stop Gracefully stop a running container
docker restart Restart a container
docker pause Pause container processes
docker unpause Resume paused processes
docker kill Forcefully stop a container using a signal
docker rm Remove a container

Example

docker stop web

docker start web

docker restart web

docker rm web
A stopped container is not automatically deleted. You must remove it separately with docker rm unless another cleanup mechanism handles it.

⭐⭐⭐⭐⭐ 6. Docker Logs

View logs

docker logs web

Follow logs

docker logs -f web

Show recent logs

docker logs --tail 100 web

Show timestamps

docker logs -t web
Production scenario: A container is repeatedly stopping. First check: 
docker ps -a

docker logs <container-name>
The logs may reveal application startup errors, configuration problems or missing dependencies.

⭐⭐⭐⭐⭐ 7. docker exec

Execute a command inside a running container

docker exec web ls

Open a shell

docker exec -it web bash

If Bash is unavailable, a minimal image may provide sh. 

docker exec -it web sh

Check environment

docker exec web env

Check processes

docker exec web ps
docker exec runs a new process inside an already running container. It is commonly used for troubleshooting and inspection.

⭐⭐⭐⭐⭐ 8. docker inspect

Inspect a container

docker inspect web

This returns detailed JSON information about the container.

Common things to investigate

  • Container IP address
  • Environment variables
  • Port mappings
  • Mounts
  • Network configuration
  • Container state
  • Restart information
  • Image used

Inspect an image

docker image inspect nginx
When an application cannot connect to another container, inspect the network configuration before changing random settings.

⭐⭐⭐⭐⭐ 9. Container Resource Usage

Live resource usage

docker stats

Specific container

docker stats web

This displays live CPU, memory, network and block I/O information.

High CPU scenario: If an application suddenly consumes excessive CPU: 
docker stats

docker logs web

docker inspect web
Then investigate the application process and host resources.

⭐⭐⭐⭐⭐ 10. Copy Files To / From Containers

Host → Container

docker cp ./config.yml web:/app/config.yml

Container → Host

docker cp web:/app/logs.txt ./logs.txt
docker cp copies files or directories between the local filesystem and a container.

⭐⭐⭐⭐⭐ 11. Container Port Inspection

Show published ports

docker port web

Example

docker run -d --name web -p 8080:80 nginx

docker port web
Use docker port when you want a quick view of the container's published port mappings.

⭐⭐⭐⭐⭐ 12. Docker Attach vs Exec

docker exec docker attach
Starts a new process inside the container Attaches to the container's existing main process
Commonly safer for troubleshooting Can interact directly with the main process
Example: open a shell Example: attach to process output 
docker exec -it web sh

docker attach web
Be careful when using docker attach because interacting with the main process can affect the container depending on how the application handles input and signals.

⭐⭐⭐⭐⭐ 13. Docker Rename

docker rename old-name new-name

Renames an existing container without changing the image.

⭐⭐⭐⭐⭐ 14. Docker Rename / Tag / Versioning

Tag an image

docker tag myapp:latest myapp:1.0

Registry tag

docker tag myapp:1.0 username/myapp:1.0

Push

docker push username/myapp:1.0

Pull

docker pull username/myapp:1.0
DevOps best practice:

Use meaningful immutable version tags for releases rather than depending only on a mutable tag such as latest.

⭐⭐⭐⭐⭐ 15. Docker System Cleanup

Check Docker disk usage

docker system df

Remove unused resources

docker system prune

More aggressive cleanup

docker system prune -a
Be careful with cleanup commands. docker system prune -a can remove unused images and other unused Docker resources. Always understand what is unused before running cleanup on an important host.

⭐⭐⭐⭐⭐ 16. Removing Containers & Images

Remove stopped container

docker rm web

Force remove running container

docker rm -f web

Remove unused containers

docker container prune

Remove unused images

docker image prune

Remove unused networks

docker network prune

Remove unused volumes

docker volume prune

🔥 ⭐⭐⭐⭐⭐ 18. Real-Time Troubleshooting Scenarios

Scenario 1 — Container is not running

docker ps -a

docker logs <container>

docker inspect <container>

Scenario 2 — Container exits immediately

docker ps -a

docker logs <container>

Check the exit status, logs and main process configured for the container.

Scenario 3 — Application is unreachable

docker ps

docker port <container>

docker logs <container>

docker inspect <container>

Scenario 4 — High memory usage

docker stats

Scenario 5 — Docker host disk is full

docker system df

docker system prune
Do not immediately delete everything. Identify unused images, containers, volumes and build cache first.
