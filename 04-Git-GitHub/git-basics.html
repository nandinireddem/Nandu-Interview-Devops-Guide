Git Basics

Core Git concepts, version control, Git vs GitHub, Git workflow and essential interview fundamentals.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

1. What is Git?

Interview Answer:

Git is a distributed version control system used to track changes in source code and collaborate with multiple developers.

It allows developers to maintain different versions of their code, create branches, merge changes and restore previous versions when required.

Example: 
Developer
   ↓
Modify Code
   ↓
git add
   ↓
git commit
   ↓
Local Repository
   ↓
git push
   ↓
GitHub
💡 DevOps Point: Git is the foundation of many CI/CD pipelines because tools like Jenkins and GitHub Actions can trigger builds whenever code is pushed.
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

2. Why is Git used in DevOps?

Interview Answer:

Git provides version control and collaboration for application and infrastructure code.

In DevOps, Git can store application source code, Dockerfiles, Kubernetes manifests and Terraform configurations.

Real-time DevOps Example: 
Developer pushes code
        ↓
GitHub
        ↓
CI Pipeline
        ↓
Build
        ↓
Test
        ↓
Docker Image
        ↓
Deployment
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

3. What is Version Control?

Interview Answer:

Version control is a system that records changes made to files over time so that developers can track, compare and restore different versions.

Git is a distributed version control system.

Simple Example:

Suppose today's application works correctly but tomorrow a developer introduces a bug. Git allows us to identify the change and restore the previous working version.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

4. What is the difference between Git and GitHub?

Git GitHub
Version control system Cloud platform for hosting Git repositories
Runs locally Runs as a web service
Tracks code changes Provides collaboration features
CLI based Web UI + Git integration
Created by Linus Torvalds GitHub is a hosting/collaboration platform
Interview line:

"Git is the version control tool, whereas GitHub is a platform that hosts Git repositories and provides collaboration features such as pull requests, issues and code reviews."

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

5. Is Git centralized or distributed?

Interview Answer:

Git is a distributed version control system (DVCS).

Every developer's local repository contains the project's history, so developers can perform many Git operations without depending on the remote repository. 

GitHub Remote Repository
          ↑
       git push
          ↑
Developer Local Repository
          ↑
       git commit
          ↑
      Working Code
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

6. What are the main areas in a Git workflow?

The commonly discussed Git workflow contains three local areas:

  1. Working Directory
  2. Staging Area
  3. Local Repository

There is also a Remote Repository, such as a repository hosted on GitHub. 

Working Directory
       ↓
    git add
       ↓
Staging Area
       ↓
  git commit
       ↓
Local Repository
       ↓
   git push
       ↓
Remote Repository
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

7. What is a Git repository?

Interview Answer:

A Git repository is a directory that contains the project's files and Git metadata used to track changes and maintain version history.

The hidden .git directory stores important Git metadata. 

my-project/
│
├── app.py
├── README.md
└── .git/
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

8. What does git init do?

Interview Answer:

git init initializes a new Git repository inside the current directory. 

mkdir my-project
cd my-project

git init

After running this command, Git creates a hidden .git directory.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

9. What does git clone do?

Interview Answer:

git clone creates a local copy of an existing remote Git repository. 

git clone https://github.com/user/project.git
Important:

Unlike git init, clone is normally used when the repository already exists remotely.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

10. What is a Git commit?

Interview Answer:

A commit is a snapshot of the staged changes stored in the local Git repository.

Each commit has a unique identifier called a commit hash. 

git add app.py

git commit -m "Add application configuration"
⭐⭐⭐⭐ IMPORTANT

11. What is the purpose of git status?

Interview Answer:

git status shows the current state of the working directory and staging area.

It helps us identify modified, untracked and staged files. 

git status
⭐⭐⭐⭐ IMPORTANT

12. What is the purpose of git log?

Interview Answer:

git log displays the commit history of a repository. 

git log

git log --oneline
🔥 REAL-TIME DEVOPS SCENARIO

13. A developer accidentally deleted a file. How can Git help?

First, check the repository status and history. If the deleted file was previously committed, Git can restore the version from a previous commit. 

git status

git log -- filename

git restore filename

The exact recovery command depends on whether the deletion is committed or still only present in the working directory.
