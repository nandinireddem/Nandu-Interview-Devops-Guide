Git Commands

Essential Git commands for DevOps interviews, daily development, branch management, collaboration and CI/CD workflows.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

1. What is git init?

Interview Answer:

git init initializes a new Git repository in the current directory.

It creates a hidden .git directory that contains Git's repository metadata. 

mkdir my-project
cd my-project

git init

Check the repository:

git status
Interview Point:

git init is normally used when starting a new local project that is not already a Git repository.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

2. What is git clone?

Interview Answer:

git clone creates a local copy of an existing remote Git repository.

It downloads the repository, its history and branches needed for normal development. 

git clone https://github.com/example/project.git

After cloning, Git automatically creates a directory containing the project.

Remember:

git init = create a new repository
git clone = copy an existing repository

⭐⭐⭐⭐⭐ MUST KNOW

3. What is git status?

Interview Answer:

git status shows the current state of the working directory and staging area.

It tells us which files are modified, staged, untracked or ready to be committed. 

git status

Typical output can show:

modified: app.py
untracked: Dockerfile
DevOps Usage:

Before committing changes, I usually run git status to verify exactly what has changed.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

4. What is git add?

Interview Answer:

git add moves changes from the Working Directory into the Staging Area. 

git add app.py

Stage all modified files:

git add .
Important:

git add does not create a commit. It only prepares the selected changes for the next commit.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

5. What is git commit?

Interview Answer:

git commit records the staged changes in the Local Repository as a new commit. 

git commit -m "Add login feature"

Every commit receives a unique commit identifier/hash.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

6. What is git push?

Interview Answer:

git push uploads local commits to a remote repository. 

git push origin main

Here origin is the remote repository name and main is the branch.

Remember:

commit → local repository
push → remote repository

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

7. What is git pull?

Interview Answer:

git pull gets changes from the remote repository and integrates them into the current local branch.

Conceptually, it performs a fetch followed by an integration operation, commonly a merge. 

git pull origin main
Real-time Example:

If another developer pushed changes to GitHub, I can use git pull to bring those changes into my local branch.

⭐⭐⭐⭐⭐ MUST KNOW

8. What is git fetch?

Interview Answer:

git fetch downloads new commits and references from the remote repository without automatically merging them into the current working branch. 

git fetch origin

After fetching, we can inspect the remote changes before deciding whether to merge or rebase them.

⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

9. git pull vs git fetch?

git fetch git pull
Downloads remote changes Downloads and integrates changes
Does not directly update current branch Usually updates current branch
Safer for inspecting changes first Convenient for regular synchronization
Interview Shortcut:

fetch = download and inspect
pull = download and integrate

⭐⭐⭐⭐ IMPORTANT

10. What is git diff?

Interview Answer:

git diff shows the differences between different states of files. 

git diff

Shows unstaged changes. 

git diff --staged

Shows changes that are currently staged.

⭐⭐⭐⭐⭐ MUST KNOW

11. What is git log?

Interview Answer:

git log displays the commit history of the repository. 

git log

Compact history:

git log --oneline

Graph view:

git log --oneline --graph --all
⭐⭐⭐⭐ IMPORTANT

12. What is git remote?

Interview Answer:

git remote is used to manage connections between the local repository and remote repositories. 

git remote -v

This displays the URLs configured for the remote repository. 

git remote add origin https://github.com/example/project.git
⭐⭐⭐⭐ IMPORTANT

13. What is git show?

Interview Answer:

git show displays information about a specific Git object, commonly a commit. 

git show

Show a specific commit:

git show abc123
⭐⭐⭐⭐ VERY USEFUL

14. What is git stash?

Interview Answer:

git stash temporarily stores uncommitted changes so that we can work on another branch without committing unfinished work. 

git stash

View stashes:

git stash list

Restore the latest stash:

git stash pop
Real-time Scenario:

I am working on Feature A, but suddenly I need to switch to a production bug-fix branch. If my current changes are not ready for a commit, I can stash them, switch branches, fix the issue and later restore my changes.

⭐⭐⭐⭐ IMPORTANT

15. What is git tag?

Interview Answer:

A Git tag is a reference used to mark a specific point in Git history, commonly used for releases. 

git tag v1.0.0

git push origin v1.0.0
DevOps Example:

A team can tag a production release as v1.0.0, making it easy to identify exactly which code version was deployed.

⭐⭐⭐⭐⭐ MUST KNOW

16. Explain a basic Git workflow using commands.

Interview Answer:

For a normal development task, I first check the repository, modify the required files, review the changes, stage them, commit them and push the commit to the remote repository. 

git status

# Review changes
git diff

# Stage changes
git add .

# Create commit
git commit -m "Add application changes"

# Push to GitHub
git push origin main
⭐⭐⭐⭐⭐ DEVOPS FAVORITE

17. How are Git commands used in a CI/CD workflow?

Interview Answer:

Git acts as the source-control layer of the CI/CD pipeline. A developer pushes code to GitHub, which can trigger Jenkins or GitHub Actions.

Developer
↓ git push
GitHub
↓ webhook / trigger
Jenkins / GitHub Actions
↓
Build → Test → Scan
↓
Deploy
🔥 REAL-TIME SCENARIO

18. You changed a file but don't want to commit it yet. What will you do?

If I need to temporarily save the changes while switching branches, I can use git stash. 

git stash

Later: 

git stash pop
🔥 REAL-TIME SCENARIO

19. Your teammate pushed new changes. How do you get them?

For normal synchronization, I can use:

git pull origin main

If I want to inspect the changes before integrating them:

git fetch origin
git log --oneline origin/main
🔥 REAL-TIME SCENARIO

20. You committed locally, but GitHub does not show the commit. Why?

Because git commit only creates the commit in the local repository.

I need to push it:

git push origin main
🔥 REAL-TIME SCENARIO

21. You want to know which files changed before committing. What do you use?

git status
git diff

git status gives the state of files, while git diff shows the actual content differences.
