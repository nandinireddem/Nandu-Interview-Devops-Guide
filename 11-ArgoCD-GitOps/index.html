Simple interview explanation: GitHub Actions handles the CI part such as build, test, scan and image publishing. ArgoCD handles continuous delivery by watching the GitOps repository and synchronizing the desired state into Kubernetes.

🧠 Quick Memory

Term Remember
GitOps Git is the source of truth for desired infrastructure/application state.
ArgoCD GitOps continuous delivery tool for Kubernetes.
Desired State What Git says the cluster should look like.
Actual State What currently exists in the cluster.
Sync Apply desired state from Git to the cluster.
Drift Difference between desired and actual state.
Self-Healing Automatically correct supported drift.
Prune Remove resources no longer defined in Git.
Rollback Return to a previous desired application state.
