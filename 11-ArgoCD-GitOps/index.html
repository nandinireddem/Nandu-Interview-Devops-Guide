Term Remember
GitOps Git is the source of truth for desired infrastructure/application state.
ArgoCD GitOps continuous delivery tool for Kubernetes.
Desired State What Git says the cluster should look like.
Actual State What currently exists in the cluster.
Sync Apply desired state from Git to the cluster.
Drift Difference between desired and actual state.
