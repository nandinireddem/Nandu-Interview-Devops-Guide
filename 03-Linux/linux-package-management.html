Linux Package Management

Package installation, repositories, dependencies, updates, troubleshooting and interview-ready DevOps scenarios.

01
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

What is Package Management?

Package management is the process of installing, updating, removing and maintaining software packages on a Linux system.

A package manager also helps resolve dependencies and obtain software from configured repositories.

Repository → Package Manager → Dependency Resolution → Installation → Configuration → Verification
Interview Answer:
"Linux package management is used to install, update, remove and maintain software packages. Package managers such as APT, DNF and YUM also handle repositories and dependencies."
02
⭐⭐⭐⭐⭐

APT — Debian / Ubuntu

APT is commonly used on Debian-based distributions such as Ubuntu.

Update Repository Metadata

sudo apt update

Upgrade Installed Packages

sudo apt upgrade

Install a Package

sudo apt install nginx

Remove a Package

sudo apt remove nginx

Remove Package + Configuration

sudo apt purge nginx

Search for a Package

apt search nginx

Show Package Information

apt show nginx

List Installed Packages

apt list --installed
Important:
apt update refreshes repository metadata. It does not upgrade installed packages by itself.
03
⭐⭐⭐⭐⭐

apt vs apt-get

Command Typical Usage
apt Modern, user-friendly interface for interactive administration.
apt-get Traditional APT command commonly used in scripts and automation. 
sudo apt update
sudo apt install nginx

sudo apt-get update
sudo apt-get install nginx
Interview Tip:
For modern interactive administration, apt is common. In automation and older scripts, you may encounter apt-get.
04
⭐⭐⭐⭐⭐

YUM — RPM-Based Systems

YUM is associated with RPM-based Linux distributions and has historically been widely used on RHEL-family systems. 

sudo yum install nginx

sudo yum update

sudo yum remove nginx

yum search nginx

yum info nginx

yum list installed
Modern RHEL-family distributions commonly use DNF. YUM may still exist as a compatibility command depending on the distribution.
05
⭐⭐⭐⭐⭐

DNF

DNF is the modern package management technology used by many current RPM-based distributions. 

sudo dnf install nginx

sudo dnf update

sudo dnf remove nginx

dnf search nginx

dnf info nginx

dnf list installed

Check Available Updates

dnf check-update
06
⭐⭐⭐⭐

RPM

RPM is the low-level package format and package-management tool used by RPM-based Linux systems.

Install Local RPM

sudo rpm -ivh package.rpm

Upgrade RPM

sudo rpm -Uvh package.rpm

Remove Package

sudo rpm -e package-name

Query Installed Package

rpm -q nginx

List Files Installed by Package

rpm -ql nginx
Important Difference:
RPM works directly with RPM packages, while DNF/YUM provide higher-level dependency and repository management.
07
⭐⭐⭐⭐⭐

Repositories

A repository is a source from which package managers obtain software packages and metadata.

Repository → Metadata → Package Manager → Package + Dependencies

Repositories allow administrators to install trusted software without manually downloading every dependency.

Why Repositories Matter

  • Centralized package distribution
  • Version management
  • Dependency resolution
  • Security updates
  • Software consistency across servers
08
⭐⭐⭐⭐⭐

Dependencies

A dependency is software required by another package for that package to function correctly.

Example:
An application may require a specific library. The package manager identifies the dependency and installs the required package when available from configured repositories.

Common Dependency Problem

Package A
   ↓
Requires Library B
   ↓
Library B missing
   ↓
Installation fails

Modern package managers generally resolve dependencies automatically when packages come from supported repositories.

⭐⭐⭐⭐

Install, Update and Upgrade — Difference

Operation Meaning
Install Add software package to the system.
Update metadata Refresh available package information.
Upgrade Update installed packages to newer versions.
Remove Uninstall a package.
Purge Remove package and associated configuration where supported.

Installing Nginx on a Linux Server

A common DevOps task is installing a web server on a Linux machine.

Ubuntu Example

sudo apt update
sudo apt install nginx
sudo systemctl enable nginx
sudo systemctl start nginx
sudo systemctl status nginx

RHEL-Based Example

sudo dnf install nginx
sudo systemctl enable nginx
sudo systemctl start nginx
sudo systemctl status nginx
Install → Enable → Start → Verify → Test → Monitor

Package Installation Fails — How Do You Troubleshoot?

  1. Check the exact error message.
  2. Verify network connectivity.
  3. Check repository configuration.
  4. Refresh package metadata.
  5. Check package availability.
  6. Check dependency errors.
  7. Check disk space.
  8. Retry installation.
df -h

sudo apt update

apt search nginx
Interview Answer:
"I first identify the exact package-manager error, then verify connectivity and repository configuration. Next I refresh the metadata, check dependencies and disk space, and retry the installation."

⭐⭐⭐⭐ SCENARIO

Disk Full During Package Installation

df -h

du -sh /var/* 2>/dev/null

df -i

Package operations can fail when the filesystem has insufficient space or inodes.

Golden Troubleshooting Flow:

Check disk → Identify large files → Check package cache → Clean safely → Verify space → Retry installation
13
⭐⭐⭐⭐ SCENARIO

Package Manager Is Locked

On Debian-based systems, another package-management process may currently be using the package database. 

ps aux | grep -E 'apt|dpkg'

sudo lsof /var/lib/dpkg/lock-frontend
Do not blindly delete lock files. First determine whether another legitimate package operation is running. Interrupting package operations incorrectly can leave the package database inconsistent.

⭐⭐⭐⭐⭐ INTERVIEW QUESTIONS

Frequently Asked Questions

Q: What is a package manager?
A: A tool used to install, update, remove and manage software packages and their dependencies.

Q: What is APT?
A: A package-management system commonly used by Debian-based distributions.

Q: What is DNF?
A: A modern package manager used by many RPM-based Linux distributions.

Q: What is RPM?
A: A package format and low-level package management tool used by RPM-based systems.

Q: What is a repository?
A: A source containing packages and package metadata.

Q: What is a dependency?
A: Software required by another package to function correctly.

Q: Difference between apt update and apt upgrade?
A: update refreshes package metadata, while upgrade updates installed packages.

Q: Why can package installation fail?
A: Repository problems, connectivity issues, missing dependencies, insufficient disk space, locks or package conflicts can cause failures.
