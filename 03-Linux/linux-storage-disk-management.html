Linux Storage & Disk Management

Disk usage, filesystems, partitions, mounts, df, du, lsblk, mount, fstab, inode, LVM basics and real-time DevOps troubleshooting.

QUESTION 01

What is Storage in Linux?

⭐⭐⭐⭐⭐ MUST KNOW

Linux storage is used to store operating system files, applications, configuration files, logs and user data.

Physical Disk ↓ Partition ↓ Filesystem ↓ Mount Point ↓ Files & Directories
💡 DevOps Example

An EC2 server may have an EBS volume attached to it. Linux can partition or format the storage and mount it at a directory such as /data.

🎤 Interview Answer

"Linux storage consists of disks or block devices that can be partitioned, formatted with a filesystem and mounted into the Linux directory structure for storing data."

QUESTION 02

What is a Block Device?

⭐⭐⭐⭐

A block device provides storage that can be accessed in fixed-size blocks. Disks and many storage volumes appear to Linux as block devices. 

lsblk

Typical device names may look like: 

/dev/xvda
/dev/nvme0n1
/dev/nvme1n1
🎤 Interview Answer

"A block device is a storage device that provides data access in blocks. In Linux, disks and cloud block storage volumes commonly appear as block devices."

COMMAND 03

lsblk

⭐⭐⭐⭐⭐ MUST KNOW

lsblk displays information about block devices, partitions and their mount points. 

lsblk
More detailed information 
lsblk -f

The -f option is useful for viewing filesystem type, label, UUID and mount point information.

🎤 Interview Answer

"I use lsblk to identify disks, partitions, filesystems and mount points. lsblk -f also shows filesystem and UUID information."

COMMAND 04

df

⭐⭐⭐⭐⭐ DEVOPS MUST KNOW

The df command displays filesystem disk space usage.

Human-readable output 
df -h
Filesystem type 
df -Th
Option Purpose
-h Human-readable sizes
-T Show filesystem type
🎤 Interview Answer

"df shows filesystem-level disk space usage. I commonly use df -h to quickly identify filesystems that are running out of space."

COMMAND 05

du

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

The du command estimates the disk space consumed by files and directories.

Directory size 
du -sh /var/log
Sizes of items in current directory 
du -sh *
Top-level directory usage 
du -h --max-depth=1 /var
🎤 Interview Answer

"I use du to find which directories or files are consuming disk space. For example, du -sh /var/log shows the approximate size of the log directory."

QUESTION 06

df vs du

⭐⭐⭐⭐⭐ VERY COMMON
df du
Filesystem usage File/directory usage
Shows available filesystem space Shows space consumed by files/directories
Useful to detect full filesystems Useful to find what is consuming space
Disk Full? ↓ df -h ↓ Which filesystem? ↓ du -sh * ↓ Which directory is large?
🎤 Interview Answer

"df tells me how much space is used and available at the filesystem level, while du helps me identify which files or directories are consuming that space."

QUESTION 07

What is a Filesystem?

⭐⭐⭐⭐⭐ MUST KNOW

A filesystem defines how data is organized, stored and retrieved on a storage device.

Common Linux filesystems 
ext4
xfs
🎤 Interview Answer

"A filesystem provides the structure used by an operating system to organize and manage files on storage devices. Common Linux filesystems include ext4 and XFS."

QUESTION 08

What does formatting a disk mean?

⭐⭐⭐⭐

Formatting a storage device or partition creates a filesystem on it so the operating system can store files using that filesystem.

Example 
sudo mkfs.ext4 /dev/xvdf1
⚠️ IMPORTANT

Running mkfs on the wrong device can destroy existing data. Always verify the device using lsblk before formatting.

QUESTION 09

What is Mounting?

⭐⭐⭐⭐⭐ MUST KNOW

Mounting makes a filesystem available at a directory in the Linux filesystem hierarchy.

Disk ↓ Filesystem ↓ Mount ↓ /data ↓ Application accesses files
Create mount point 
sudo mkdir /data
Mount filesystem 
sudo mount /dev/xvdf1 /data
Check mounts 
mount | grep /data
🎤 Interview Answer

"Mounting attaches a filesystem to a directory in the Linux filesystem hierarchy, making the storage accessible through that mount point."

COMMAND 10

umount

⭐⭐⭐⭐

umount detaches a mounted filesystem from its mount point. 

sudo umount /data
⚠️ Important

A filesystem may fail to unmount if a process is currently using files or directories under that mount point.

QUESTION 11

What is /etc/fstab?

⭐⭐⭐⭐⭐ DEVOPS MUST KNOW

/etc/fstab contains filesystem mount configuration that can be used to mount filesystems automatically during boot. 

cat /etc/fstab
Server Reboot ↓ Read /etc/fstab ↓ Mount configured filesystems ↓ Storage Available
🎤 Interview Answer

"/etc/fstab contains persistent filesystem mount configuration. It allows filesystems to be mounted automatically during system boot."

QUESTION 12

What is UUID?

⭐⭐⭐⭐⭐ MUST KNOW

UUID stands for Universally Unique Identifier. Filesystems can have UUIDs that provide stable identifiers for mounting. 

blkid
or 
lsblk -f
🎤 Interview Answer

"UUID is a unique identifier associated with a filesystem. Using UUIDs in /etc/fstab can provide more stable mount configuration than relying only on device names."

QUESTION 13

What is an Inode?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE

An inode stores metadata about a filesystem object such as file type, permissions, ownership and timestamps, along with pointers to the file's data blocks.

Check inode usage 
df -i
🔥 Real-Time Problem

A server can report "No space left on device" even when df -h shows free disk space if the filesystem has run out of inodes.

🎤 Interview Answer

"An inode stores filesystem metadata about a file. If a filesystem runs out of inodes, new files may not be created even when there is still free disk capacity."

QUESTION 14

What is a Partition?

⭐⭐⭐⭐

A partition is a logical division of a physical disk or block device. 

lsblk

Example: 

/dev/nvme0n1
├── /dev/nvme0n1p1
└── /dev/nvme0n1p2
QUESTION 15

What is LVM?

⭐⭐⭐⭐⭐ MUST KNOW

LVM stands for Logical Volume Manager. It provides a flexible way to manage storage using logical volumes.

Physical Disk ↓ Physical Volume (PV) ↓ Volume Group (VG) ↓ Logical Volume (LV) ↓ Filesystem ↓ Mount Point
🎤 Interview Answer

"LVM is a storage management framework that abstracts physical storage into logical volumes. It provides flexibility for creating, resizing and managing storage."

🔥 REAL-TIME DEVOPS SCENARIO

Disk is 100% full. What will you do?

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
Disk Alert ↓ df -h ↓ Identify Full Filesystem ↓ du -sh * ↓ Find Large Directories ↓ Check Logs / Temporary Files ↓ Clean Safely ↓ Verify df -h Again
Step 1 — Check filesystem usage 
df -h
Step 2 — Find large directories 
sudo du -h --max-depth=1 /var
Step 3 — Check logs 
sudo du -sh /var/log/*
Step 4 — Check inode usage 
df -i
⚠️ Never blindly delete files

Do not randomly remove system files or active application files. First identify what is consuming space and understand whether it is safe to remove, rotate or archive it.

🎤 Strong Interview Answer

"First I would use df -h to identify the full filesystem. Then I would use du to locate large directories or files. I would also check inode usage with df -i. After identifying the cause, I would safely clean, rotate or archive unnecessary data and verify the available space again."

🔥 REAL-TIME SCENARIO

df shows high usage but du doesn't show the same usage

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE

One possible cause is a deleted file that is still held open by a running process.

Find deleted-but-open files 
sudo lsof +L1
File Deleted ↓ Process Still Has File Open ↓ Disk Blocks Still Occupied ↓ df Shows Usage ↓ du Does Not Show Deleted File
🎤 Interview Answer

"If df shows significantly more usage than du, I would investigate deleted files that are still held open by running processes using lsof. The disk space is released when the process closes the file."

QUESTION 17

AWS EBS and Linux Storage

⭐⭐⭐⭐⭐ CLOUD + DEVOPS

Amazon EBS provides persistent block storage volumes that can be attached to EC2 instances.

AWS EBS Volume ↓ EC2 Instance ↓ Linux Block Device ↓ Filesystem ↓ Mount Point ↓ Application

After attaching a volume, you may need to: 

lsblk
sudo mkfs.ext4 /dev/DEVICE
sudo mkdir /data
sudo mount /dev/DEVICE /data
df -h
⚠️ Important

Do not run mkfs on an existing volume containing important data. Always identify the correct device first.

🔥 DEVOPS TROUBLESHOOTING

New Disk Attached but Not Visible in Application

⭐⭐⭐⭐⭐
Disk Attached ↓ lsblk ↓ Partition? ↓ Filesystem? ↓ Mount Point? ↓ df -h ↓ Application Configuration
Useful commands 
lsblk
lsblk -f
sudo blkid
df -h
mount
cat /etc/fstab
🎤 Strong Answer

"I would first confirm that Linux detects the block device using lsblk. Then I would check whether it has a filesystem, verify the mount point and confirm that the filesystem is mounted. Finally, I would verify /etc/fstab if persistent mounting is required and check whether the application is using the correct path."
