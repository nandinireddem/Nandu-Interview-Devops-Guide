Linux File & Directory Commands

Essential Linux commands for navigating, creating, copying, moving, deleting and locating files and directories.

COMMAND 01

pwd — Print Working Directory

⭐⭐⭐⭐⭐ MUST KNOW

The pwd command displays the absolute path of the current working directory.

💡 Example 
pwd

Output:

/home/nandu/projects
🎤 Interview Answer

"The pwd command displays the absolute path of the current working directory."

COMMAND 02

ls — List Files and Directories

⭐⭐⭐⭐⭐ MUST KNOW

The ls command lists files and directories in the current directory.

Common options

Command Purpose
ls List files and directories
ls -l Detailed listing
ls -a Show hidden files
ls -lh Human-readable file sizes
ls -la Detailed listing including hidden files
💡 Example 
ls
ls -l
ls -la
ls -lh
🎤 Interview Answer

"The ls command is used to list files and directories. Common options include -l for detailed information, -a to show hidden files and -h for human-readable sizes."

COMMAND 03

cd — Change Directory

⭐⭐⭐⭐⭐ MUST KNOW

The cd command is used to move between directories.

💡 Examples 
cd /var/log

cd /home

cd ..

cd ~

cd -
Command Meaning
cd .. Move to parent directory
cd ~ Move to user's home directory
cd - Move to previous directory
cd /path Move to specified directory
🎤 Interview Answer

"The cd command is used to change the current working directory. It can be used with absolute paths, relative paths, .. for the parent directory and ~ for the user's home directory."

COMMAND 04

mkdir — Create Directory

⭐⭐⭐⭐⭐ MUST KNOW

The mkdir command creates a new directory.

💡 Examples 
mkdir project

mkdir devops

mkdir -p project/app/logs

The -p option creates parent directories when they do not already exist.

🎤 Interview Answer

"mkdir is used to create directories. The -p option allows us to create a directory structure including any missing parent directories."

COMMAND 05

touch — Create File

⭐⭐⭐⭐

The touch command can create an empty file and can also update file timestamps.

💡 Example 
touch app.txt

touch config.yaml

touch file1 file2 file3
🎤 Interview Answer

"The touch command is commonly used to create empty files. It can also update the access and modification timestamps of existing files."

COMMAND 06

cp — Copy Files and Directories

⭐⭐⭐⭐⭐ MUST KNOW

The cp command copies files or directories from one location to another.

💡 Examples 
cp app.txt backup.txt

cp app.txt /tmp/

cp -r project project-backup

The -r option is used to copy directories recursively.

🎤 Interview Answer

"The cp command copies files and directories. For directories, the recursive option -r is commonly used."

COMMAND 07

mv — Move or Rename

⭐⭐⭐⭐⭐ MUST KNOW

The mv command is used to move files or directories and can also be used to rename them.

💡 Examples 
mv app.txt /tmp/

mv oldname.txt newname.txt

mv project /opt/project
🎤 Interview Answer

"The mv command is used to move files or directories. It can also rename a file or directory when the source and destination are in the same location."

COMMAND 08

rm — Remove Files and Directories

⭐⭐⭐⭐⭐ MUST KNOW

The rm command removes files and directories.

💡 Examples 
rm app.txt

rm -r project

rm -f app.txt

rm -rf project

Be extremely careful with rm -rf because it can recursively and forcefully delete data.

🎤 Interview Answer

"The rm command removes files and directories. The -r option allows recursive deletion of directories, while -f forces deletion without interactive confirmation. It should be used carefully."

COMMAND 09

find — Search Files and Directories

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

The find command searches for files and directories based on conditions such as name, type, size and modification time.

💡 Examples 
find /var/log -name "*.log"

find /home -name "app.txt"

find . -type f

find . -type d

find /tmp -type f -size +100M
Option Purpose
-name Search by name
-type f Search files
-type d Search directories
-size Search based on file size
🔥 Real-Time DevOps Example

If a production server has many log files and you need to find all .log files under /var/log: 

find /var/log -type f -name "*.log"
🎤 Interview Answer

"find is a powerful Linux command used to search files and directories based on conditions such as name, type and size. It is frequently useful during server troubleshooting."

COMMAND 10

Directory Structure Navigation

⭐⭐⭐⭐

Linux directories form a hierarchical tree starting from /.

/ ↓ home ↓ nandu ↓ projects ↓ devops
💡 Example 
pwd
ls
cd projects
ls
cd ..
pwd
QUESTION 11

What are Hidden Files?

⭐⭐⭐⭐

In Linux, files and directories whose names begin with a dot (.) are commonly treated as hidden.

💡 Examples 
.bashrc
.profile
.git
.gitignore

To display hidden files: 

ls -a
🎤 Interview Answer

"Linux commonly treats files and directories beginning with a dot as hidden. They can be displayed using ls -a."

REAL-TIME PRACTICE

🔥 Create a Project Directory Structure

⭐⭐⭐⭐⭐ DEVOPS PRACTICAL

Suppose you need to create a basic application structure on a Linux server.

Step 1 — Create directories 
mkdir -p devops-project/{app,config,logs,backup}
Step 2 — Enter the project 
cd devops-project
Step 3 — Create files 
touch app/app.py
touch config/app.conf
Step 4 — Verify 
ls -la
ls -la app
ls -la config
Step 5 — Create backup 
cp -r app backup/
🎤 Interview Answer

"I can use mkdir and touch to create the required project structure, cd and ls to navigate and verify it, and cp or mv to copy or move application files."

SCENARIO

🎯 File or Directory Not Found

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE

If a file or directory is not found, I would first verify my current location and then search for the required resource. 

pwd
ls -la
find / -name "filename" 2>/dev/null

The issue may be caused by:

→ Wrong directory
→ Incorrect filename
→ Case-sensitive filename
→ File was moved
→ File was deleted

🎤 Strong Answer

"First I would check the current working directory using pwd and list its contents using ls -la. If the file is not there, I would use find to locate it and verify the exact filename and path."

🧠 FINAL REVISION — FILE & DIRECTORY COMMANDS

pwd → Show current directory.

ls → List files and directories.

cd → Change directory.

mkdir → Create directory.

touch → Create empty file / update timestamp.

cp → Copy files or directories.

mv → Move or rename.

rm → Remove files or directories.

find → Search files and directories.

Absolute Path → Complete path starting from /.

Relative Path → Path relative to the current directory.

Hidden File → Usually starts with ..

Golden Troubleshooting Flow

pwd → ls -la → verify path → find → troubleshoot
