Linux Shell Scripting

Bash scripting, variables, conditions, loops, functions, exit codes and practical DevOps automation.

01
⭐⭐⭐⭐⭐ VERY FREQUENTLY ASKED

What is Shell Scripting?

Shell scripting is the practice of writing a sequence of commands in a script file so that Linux tasks can be executed automatically.

Bash is one of the most commonly used shells for Linux automation and DevOps tasks.

Script → Execute Commands → Check Result → Take Action → Exit
Interview Answer:
"Shell scripting is used to automate repetitive Linux tasks. In DevOps, Bash scripts are commonly used for server setup, deployment, backups, health checks and operational automation."

Basic Bash Script

#!/bin/bash

echo "Hello DevOps"

The first line is called the shebang. It tells the system which interpreter should execute the script.

Make Script Executable

chmod +x script.sh

Run Script

./script.sh

Run Through Bash

bash script.sh

Variables

name="Nandu"

echo "$name"

Do not put spaces around the equals sign when assigning a variable.

Use quotes around variables when their values may contain spaces.

Command-Line Arguments

Variable Meaning
$0 Script name
$1 First argument
$2 Second argument
$@ All positional arguments
$# Number of positional arguments
$? Exit status of previous command

⭐⭐⭐⭐⭐

Exit Codes

Linux commands normally return an exit status. By convention, 0 means success and a non-zero value indicates failure. 

ls /tmp

echo $?
0 → Success

Non-zero → Failure / abnormal result

Why DevOps Engineers Care

CI/CD pipelines and automation scripts can use exit codes to decide whether a step succeeded or failed.

if / elif / else

#!/bin/bash

if [ "$1" = "prod" ]; then
    echo "Production environment"
elif [ "$1" = "dev" ]; then
    echo "Development environment"
else
    echo "Unknown environment"
fi

Conditions are commonly used to make scripts behave differently depending on system state or user input.

⭐⭐⭐⭐⭐

File and Directory Conditions

if [ -f "/etc/hosts" ]; then
    echo "File exists"
fi

if [ -d "/var/log" ]; then
    echo "Directory exists"
fi
Test Meaning
-f Regular file exists
-d Directory exists
-r Readable
-w Writable
-x Executable

for Loop

for server in web1 web2 web3
do
    echo "Checking $server"
done

Useful DevOps Example

for file in /var/log/*.log

    echo "Checking $file"
done

Loops are useful when the same operation needs to be performed against multiple files, servers or values.

09
⭐⭐⭐⭐

while Loop

count=1

while [ "$count" -le 5 ]
do
    echo "Count: $count"
    count=$((count + 1))
done

A while loop continues executing while its condition remains true.

case Statement

case "$1" in
    start)
        echo "Starting application"
        ;;
    stop)
        echo "Stopping application"
        ;;
    restart)
        echo "Restarting application"
        ;;
    *)
        echo "Usage: $0 {start|stop|restart}"
        ;;
esac
When is case useful?
It is useful when a script needs to handle multiple predefined options such as start, stop, restart, status or deploy.

Command Substitution

current_date=$(date)

Example

Pipes and Redirection

cat app.log | grep ERROR

A pipe sends the output of one command as input to another. 

echo "deployment complete" > deployment.log

echo "new entry" >> deployment.log

command 2> error.log

command > output.log 2>&1
Operator Purpose
| Pipe output to another command
> Write/overwrite output
>> Append output
2> Redirect stderr
&> Redirect stdout and stderr in Bash

⭐⭐⭐⭐⭐

set -e and Safer Scripts

#!/bin/bash

set -e

echo "Starting deployment"

mkdir /tmp/example

echo "Deployment step completed"

With set -e, Bash generally exits when a command returns a non-zero status in contexts where the failure is not explicitly handled.

Do not assume set -e makes every script completely safe. Bash error handling has important exceptions, especially inside conditions, pipelines and compound commands.

Application Deployment Script

#!/bin/bash

set -e

APP_DIR="/opt/myapp"

echo "Starting deployment"

cd "$APP_DIR"

echo "Pulling latest code"
git pull

echo "Installing dependencies"
npm install

echo "Restarting application"
sudo systemctl restart myapp

echo "Checking service"
sudo systemctl status myapp --no-pager

echo "Deployment completed"
Validate → Pull Code → Install → Restart → Verify → Report

⭐⭐⭐⭐⭐ REAL-TIME SCENARIO

Disk Health Check Script

#!/bin/bash

THRESHOLD=80

usage=$(df / | awk 'NR==2 {print $5}' | tr -d '%')

if [ "$usage" -ge "$THRESHOLD" ]; then
    echo "WARNING: Disk usage is ${usage}%"
    exit 1
else
    echo "Disk usage is ${usage}%"
fi

This type of script can be integrated into operational checks or monitoring workflows.

17
⭐⭐⭐⭐⭐ REAL-TIME SCENARIO

Service Health Check

#!/bin/bash

SERVICE="nginx"

if systemctl is-active --quiet "$SERVICE"; then
    echo "$SERVICE is running"
else
    echo "$SERVICE is DOWN"
    exit 1
fi
DevOps Usage:
A health-check script can be used during deployments, troubleshooting or automated validation.

⭐⭐⭐⭐⭐ INTERVIEW QUESTIONS

Frequently Asked Shell Scripting Questions

Q: What is shell scripting?
A: Automating Linux operations by executing a sequence of shell commands from a script.

Q: What is Bash?
A: Bash is a widely used Unix/Linux shell and scripting language.

Q: What does #!/bin/bash mean?
A: It specifies Bash as the interpreter for the script.

Q: What does $? represent?
A: The exit status of the previous command.

Q: What does $1 represent?
A: The first positional argument supplied to the script.

Q: Difference between $@ and $#?
A: $@ represents the positional arguments, while $# represents their count.

Q: What is a function?
A: A reusable block of commands.

Q: Why are exit codes important in DevOps?
A: Automation systems use exit status to determine whether a command or step succeeded or failed.

Q: Where is shell scripting used in DevOps?
A: Server setup, deployment, backups, health checks, log processing, CI/CD automation and troubleshooting.

Shebang → Specifies the script interpreter.

Variable → Stores a value.

$0 → Script name.

$@ → Positional arguments.

$# → Number of arguments.

$? → Previous command's exit status.

if → Conditional logic.

for → Iterate over values.

while → Repeat while condition is true.

case → Handle multiple options.

function → Reusable logic.

| → Pipe output.

> → Redirect/overwrite output.

>> → Append output.

DevOps Golden Flow

Validate → Execute → Check Exit Code → Handle Failure → Verify → Report
