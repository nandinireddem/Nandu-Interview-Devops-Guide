Linux SSH & Remote Access

SSH, authentication, SSH keys, SCP, rsync and practical remote-server troubleshooting.

QUESTION 01

What is SSH?

⭐⭐⭐⭐⭐ MUST KNOW

SSH stands for Secure Shell. It is a network protocol used to securely connect to and manage remote systems. 

ssh username@server-ip
Example: 
ssh ec2-user@13.233.10.20

This establishes a secure remote shell session with the server.

🎤 Interview Answer

"SSH is a secure remote-access protocol used to connect to and manage Linux servers over an encrypted connection."

QUESTION 03

Basic SSH Command

⭐⭐⭐⭐⭐ 
ssh username@hostname

You can also specify a custom SSH port using -p. 

ssh -p 2222 username@server-ip
Remember:

Default SSH port is 22.

"SSH key authentication uses a public and private key pair instead of relying on a password. It is widely used for secure and automated server access."

An SSH key pair consists of:

  • Private key — kept secret on the client.

QUESTION 06

How do you generate an SSH key?

⭐⭐⭐⭐⭐ 
ssh-keygen -t ed25519

This generates an Ed25519 key pair on systems that support it. RSA is also commonly encountered: 

ssh-keygen -t rsa -b 4096

The generated files commonly include a private key and a public key ending in .pub.

QUESTION 07

What is authorized_keys?

⭐⭐⭐⭐⭐ DEVOPS MUST KNOW

On Linux servers, the user's SSH public keys are commonly stored in: 

~/.ssh/authorized_keys

When a matching private key is used by the client, SSH can authenticate the user without requiring the normal password flow.

🎤 Interview Answer

"The authorized_keys file contains public keys that are allowed to authenticate for a particular Linux user."

QUESTION 08

What are SSH file permissions?

⭐⭐⭐⭐⭐ IMPORTANT

SSH is sensitive to permissions on key files. A private key should not be broadly readable by other users. 

chmod 600 ~/.ssh/id_ed25519

The SSH directory itself is commonly restricted as well: 

chmod 700 ~/.ssh
Common problem:

If a private key is too permissive, SSH may refuse to use it.

QUESTION 09

How do you specify an SSH private key?

⭐⭐⭐⭐⭐ 
ssh -i my-key.pem ec2-user@server-ip

The -i option specifies the identity/private-key file.

AWS example: 
ssh -i nandu-key.pem ec2-user@<EC2-PUBLIC-IP>
QUESTION 10

What is SCP?

⭐⭐⭐⭐⭐ MUST KNOW

SCP stands for Secure Copy Protocol. It is used to securely copy files between systems over SSH.

Local → Remote

scp file.txt user@server:/home/user/

Remote → Local

scp user@server:/home/user/file.txt .

Directory

scp -r project/ user@server:/home/user/
QUESTION 11

SCP vs SSH

SSH SCP
Remote shell/access File transfer
Run commands remotely Copy files/directories
ssh user@server scp file user@server:path
QUESTION 12

What is rsync?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

rsync is commonly used to synchronize files and directories efficiently between locations. 

rsync -av project/ user@server:/home/user/project/

It can transfer only changed portions/files depending on the synchronization scenario, making it useful for repeated transfers.

QUESTION 13

SCP vs rsync

⭐⭐⭐⭐⭐ INTERVIEW FAVORITE
SCP rsync
Simple file copying Synchronization
Easy for one-time transfers Useful for repeated transfers
Less synchronization-focused Efficient for changed data
🎤 Interview Answer

"I use SCP for straightforward file transfers and rsync when I need efficient synchronization between source and destination, especially for repeated transfers."

🔥 REAL-TIME SCENARIO

SSH Connection Refused

⭐⭐⭐⭐⭐ MUST PRACTICE 
ssh user@server-ip

If you receive:

Connection refused

the target host may be reachable, but the connection is being actively refused. Investigate whether the SSH service is running and whether the expected port is listening. 

systemctl status ssh
systemctl status sshd
ss -lntp
Also check:
  • Correct IP address
  • Correct SSH port
  • Firewall rules
  • Cloud security-group rules
  • SSH service configuration
🔥 REAL-TIME SCENARIO

SSH Connection Timed Out

⭐⭐⭐⭐⭐ 
ssh: connect to host server port 22: Connection timed out

A timeout commonly points toward a network path or filtering problem rather than simply an SSH authentication failure.

🔥 REAL-TIME SCENARIO

Permission Denied (publickey)

⭐⭐⭐⭐⭐ VERY COMMON 
Permission denied (publickey)

This usually means SSH key authentication did not succeed.

Check

  • Correct username
  • Correct private key
  • Correct server public key
  • Private-key permissions
  • authorized_keys
  • SSH configuration
chmod 600 my-key.pem
🎤 Interview Answer

"For public-key authentication failures, I verify the username, private key, corresponding public key, authorized_keys and SSH permissions before checking the SSH daemon configuration."

QUESTION 17

How do you debug SSH in detail?

⭐⭐⭐⭐⭐ 
ssh -v user@server-ip

For more detailed debugging: 

ssh -vvv user@server-ip

Verbose output can help identify where authentication or connection setup is failing.

QUESTION 18

What is SSH Agent?

⭐⭐⭐⭐

ssh-agent can hold private keys in memory so that SSH operations can use them without repeatedly supplying the key passphrase. 

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

This is especially useful when working with multiple SSH operations during a session.

QUESTION 19

What is known_hosts?

⭐⭐⭐⭐⭐ MUST KNOW

SSH commonly stores information about previously contacted servers in: 

~/.ssh/known_hosts

This helps SSH detect unexpected changes to a server's host key.

⚠️ Security Concept

Do not blindly ignore host-key warnings. They can indicate a legitimate server change, but they can also indicate a man-in-the-middle attack.

QUESTION 20

What is the SSH configuration file?

⭐⭐⭐⭐

The client-side configuration is commonly: 

~/.ssh/config

It allows convenient host-specific settings. 

Host myserver
    HostName 192.168.1.20
    User ubuntu
    IdentityFile ~/.ssh/id_ed25519

Then connect simply with:

ssh myserver

🎤 FINAL INTERVIEW QUESTIONS

Q: What is SSH?
A: A secure protocol for remote access to systems.

Q: What is the default SSH port?
A: 22.

Q: What is the difference between public and private keys?
A: The public key is placed on the server; the private key remains secret with the client.

Q: What is SCP?
A: A command used to securely copy files over SSH.

Q: SCP vs rsync?
A: SCP is simple file copying; rsync is designed for efficient synchronization.

Q: What does Permission denied (publickey) mean?
A: SSH public-key authentication failed.

Q: How do you debug SSH?
A: Use ssh -v or ssh -vvv and check keys, usernames, permissions and server configuration.

Q: Connection timed out vs refused?
A: Timeout commonly indicates a network/filtering issue; refused means the destination actively rejected the connection, often because the service is not listening or access is being rejected.
