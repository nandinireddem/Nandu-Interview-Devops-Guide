Linux Text Processing Commands

Essential Linux commands for reading files, searching logs, filtering output and processing text in DevOps environments.

COMMAND 01

cat — Display File Content

⭐⭐⭐⭐⭐ MUST KNOW

The cat command is used to display the contents of a file directly in the terminal.

💡 Examples 
cat app.txt

cat config.yaml

cat file1.txt file2.txt

It can also be used to create or combine files. 

cat file1.txt file2.txt > combined.txt
🎤 Interview Answer

"The cat command is used to display file contents in the terminal. It can also be used to concatenate multiple files."

COMMAND 02

less — View Large Files

⭐⭐⭐⭐⭐ VERY COMMON

The less command allows us to view large files page by page without loading the entire file into the terminal.

💡 Example 
less /var/log/syslog

Useful keys while inside less:

Key Purpose
Space Next page
b Previous page
/keyword Search
q Quit
🎤 Interview Answer

"less is used to view large files interactively, allowing us to scroll through the content and search without printing the entire file at once."

COMMAND 03

head — View Beginning of a File

⭐⭐⭐⭐

The head command displays the beginning of a file. By default, it normally shows the first 10 lines.

💡 Examples 
head app.log

head -n 20 app.log

The second command displays the first 20 lines.

🎤 Interview Answer

"head is used to display the beginning of a file. By default it shows the first ten lines, and the number can be changed using the -n option."

COMMAND 04

tail — View End of a File

⭐⭐⭐⭐⭐ DEVOPS FAVORITE

The tail command displays the end of a file. It is especially useful for checking recent log entries.

💡 Examples 
tail app.log

tail -n 20 app.log

tail -f app.log

tail -f continuously follows a file as new content is added.

🔥 Real-Time DevOps Example

An application is running on a production Linux server and you want to monitor new log entries in real time. 

tail -f /var/log/app.log
🎤 Interview Answer

"tail displays the end of a file. In DevOps, tail -f is commonly used to monitor application or system logs in real time."

COMMAND 05

grep — Search Text

⭐⭐⭐⭐⭐ MUST KNOW

The grep command searches for matching text or patterns inside files or command output.

💡 Examples 
grep "ERROR" app.log

grep "failed" app.log

grep -i "error" app.log

grep -n "ERROR" app.log
Option Purpose
-i Ignore case
-n Show line numbers
-r Search recursively
-v Show non-matching lines
🔥 Real-Time DevOps Example

Find all ERROR entries in an application log: 

grep "ERROR" /var/log/app.log

Search recursively inside an application directory: 

grep -r "database" /var/log/
🎤 Interview Answer

"grep is used to search for specific text or patterns in files or command output. It is commonly used by DevOps engineers for log analysis and troubleshooting."

CONCEPT 06

Pipe ( | )

⭐⭐⭐⭐⭐ MUST KNOW

A pipe sends the output of one command as the input to another command.

Command 1 ↓ Output ↓ | ↓ Command 2
💡 Examples 
ls -l | grep ".log"

ps aux | grep nginx

cat app.log | grep ERROR
🎤 Interview Answer

"A pipe is used to pass the output of one command as input to another command. It allows us to combine Linux commands for efficient filtering and processing."

COMMAND 07

wc — Word, Line and Character Count

⭐⭐⭐⭐

The wc command counts lines, words and bytes or characters depending on the options used.

💡 Examples 
wc app.log

wc -l app.log

wc -w app.txt

wc -c app.txt
Option Purpose
-l Count lines
-w Count words
-c Count bytes
🔥 Example

Count the number of ERROR lines: 

grep "ERROR" app.log | wc -l
🎤 Interview Answer

"wc is used to count lines, words and bytes in files. Combined with grep and pipes, it can be useful for log analysis."

COMMAND 08

sort — Sort Text

⭐⭐⭐

The sort command sorts lines of text.

💡 Examples 
sort names.txt

sort -r names.txt

sort -n numbers.txt
Option Purpose
-r Reverse order
-n Numeric sorting
🎤 Interview Answer

"The sort command arranges lines of text in a specified order. Options can be used for reverse or numeric sorting."

COMMAND 09

uniq — Remove Repeated Lines

⭐⭐⭐

The uniq command removes or reports repeated adjacent lines.

💡 Example 
sort names.txt | uniq

To count repeated entries: 

sort app.log | uniq -c
🎤 Interview Answer

"uniq is used to remove or count repeated adjacent lines. It is often combined with sort when analyzing repeated values."

COMMAND 10

cut — Extract Fields

⭐⭐⭐⭐

The cut command extracts selected sections or fields from each line of text.

💡 Example

Suppose a file contains: 

nandu:devops:1001
rahul:developer:1002
anil:admin:1003

Extract the first field: 

cut -d ":" -f 1 users.txt

Output: 

nandu
rahul
anil
🎤 Interview Answer

"cut is used to extract specific fields or sections from text. The -d option specifies the delimiter and -f selects the field."

COMMAND 11

awk — Text Processing

⭐⭐⭐⭐⭐ DEVOPS INTERVIEW

awk is a powerful text-processing and pattern-scanning tool used to process structured text and fields.

💡 Example 
awk '{print $1}' users.txt

Print the first field from each line.

For colon-separated data: 

awk -F ":" '{print $1}' /etc/passwd
🔥 Real-Time DevOps Example

Suppose a command produces multiple columns and you need only one particular column. 

ps aux | awk '{print $1}'

This can be useful when processing command output.

🎤 Interview Answer

"awk is a powerful Linux text-processing tool used for pattern matching, field extraction and processing structured text. It is especially useful when working with command output and logs."

COMMAND 12

sed — Stream Editor

⭐⭐⭐⭐⭐ DEVOPS INTERVIEW

sed is a stream editor used to search, replace, delete and transform text.

💡 Example — Replace text 
sed 's/old/new/' file.txt

Replace all matching occurrences on each line: 

sed 's/old/new/g' file.txt
🔥 Real-Time DevOps Example

Suppose an application configuration contains an old server address and you need to replace it automatically during a deployment. 

sed -i 's/old-server/new-server/g' config.txt
🎤 Interview Answer

"sed is a stream editor used to search, replace, delete and transform text. It is commonly used in Linux automation and deployment scripts to modify configuration files."

CONCEPT 13

Input and Output Redirection

⭐⭐⭐⭐⭐ MUST KNOW

Linux provides operators to redirect command input and output.

Operator Purpose
> Write output to a file and overwrite it
>> Append output to a file
< Use a file as command input
2> Redirect standard error
💡 Examples 
ls > files.txt

echo "hello" >> app.log

command 2> error.log

command > output.log 2>&1
⚠️ Important

> overwrites the destination file. Use >> when you want to append instead.

🎤 Interview Answer

"Linux redirection allows command input and output to be redirected. The greater-than operator writes or overwrites a file, double greater-than appends output, and 2> redirects standard error."

🔥 REAL-TIME DEVOPS SCENARIO

Application is throwing errors. How would you check the logs?

⭐⭐⭐⭐⭐ VERY COMMON
Application ↓ Log File ↓ tail ↓ grep ↓ wc / sort / awk ↓ Identify Problem
Step 1 — Watch recent logs 
tail -f app.log
Step 2 — Find errors 
grep "ERROR" app.log
Step 3 — Count errors 
grep "ERROR" app.log | wc -l
Step 4 — Search recursively 
grep -r "ERROR" /var/log/
Step 5 — Extract useful information 
grep "ERROR" app.log | awk '{print $1,$2,$NF}'
🎤 Strong Interview Answer

"First I would inspect the latest logs using tail or tail -f. Then I would use grep to filter ERROR or WARN messages. If necessary, I would combine grep with wc, sort or awk to count, sort or extract useful information. Based on the error pattern, I would investigate the application, system or dependency causing the issue."

COMMAND COMBINATIONS

⭐ Important DevOps Command Combinations

Command Purpose
ps aux | grep nginx Find nginx processes
cat app.log | grep ERROR Find errors
grep ERROR app.log | wc -l Count errors
sort file.txt | uniq Remove duplicate adjacent lines
grep ERROR app.log | sort Sort matching entries
tail -f app.log | grep ERROR Watch new error entries

Q: head?
A: Displays the beginning of a file.

Q: tail?
A: Displays the end of a file.

Q: Why is tail -f important?
A: It continuously follows new log entries.

Q: What is grep?
A: Searches text or patterns in files/output.

Q: What is a pipe?
A: Passes output from one command to another.

Q: What is awk?
A: Powerful text-processing and field-extraction tool.

Q: What is sed?
A: Stream editor used for text transformation and replacement.

A: Appends output to a file.

sort → Sort text.

cut → Extract fields.

sed → Search and transform text.
