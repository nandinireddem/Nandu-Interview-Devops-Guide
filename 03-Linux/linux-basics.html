Linux Basics

Linux fundamentals, architecture, kernel, shell, distributions and essential DevOps interview concepts.

QUESTION 01

What is Linux?

⭐⭐⭐⭐⭐ MUST KNOW

Linux is an open-source operating system kernel that is used as the foundation of many operating systems and server environments.

In practical usage, the term "Linux" commonly refers to Linux distributions that include the Linux kernel together with system utilities, libraries and applications.

💡 Simple Example

When you launch an AWS EC2 instance using Amazon Linux or Ubuntu, you are running a Linux-based operating system.

🎤 Interview Answer

"Linux is an open-source operating system kernel. Linux-based distributions combine the kernel with system utilities, libraries and applications to provide a complete operating system environment. Linux is widely used for servers, cloud infrastructure and DevOps."

QUESTION 02

Why is Linux important in DevOps?

⭐⭐⭐⭐⭐ VERY COMMON

Linux is widely used in cloud and server environments, making Linux administration an important DevOps skill.

→ AWS EC2 servers frequently run Linux
→ Docker containers commonly use Linux-based environments
→ Kubernetes nodes commonly run Linux
→ CI/CD tools are commonly deployed on Linux
→ Web servers and application servers commonly use Linux
→ Shell scripting is widely used for automation

🔥 Real-Time DevOps Example

A DevOps engineer may connect to an EC2 Linux server through SSH, check CPU usage, inspect logs, restart a service and troubleshoot network connectivity.

🎤 Interview Answer

"Linux is important in DevOps because many cloud servers, containers, CI/CD systems and production workloads run on Linux. It also provides powerful command-line tools and scripting capabilities for automation and troubleshooting."

QUESTION 03

What is the Linux Kernel?

⭐⭐⭐⭐⭐ MUST KNOW

The kernel is the core component of the operating system. It manages communication between hardware and software and controls important system resources.

Applications ↓ Shell / System Libraries ↓ Linux Kernel ↓ CPU • Memory • Disk • Network • Hardware

Major responsibilities of the Kernel

→ Process management
→ Memory management
→ Device management
→ File system management
→ Networking
→ Security and access control

🎤 Interview Answer

"The Linux kernel is the core of the operating system. It manages system resources such as CPU, memory, devices, storage and networking and provides the interface between applications and hardware."

QUESTION 04

What is a Shell?

⭐⭐⭐⭐⭐ MUST KNOW

A shell is a command-line interface that allows users to interact with the operating system by executing commands.

User ↓ Shell ↓ Kernel ↓ Hardware / System Resources
💡 Example

When you type: 

ls
pwd
cd /var/log
systemctl status nginx

the shell interprets the commands and requests the operating system to perform the required operations.

🎤 Interview Answer

"A shell is a command-line interface between the user and the operating system. It interprets user commands and communicates with the operating system to execute them."

QUESTION 05

What is Bash?

⭐⭐⭐⭐⭐

Bash stands for Bourne Again Shell. It is one of the most widely used shells in Linux environments.

Bash can execute commands interactively and can also run shell scripts for automation.

💡 Example 
#!/bin/bash

echo "Hello DevOps"
🎤 Interview Answer

"Bash is a widely used Linux shell and scripting language. It allows users to execute commands interactively and automate tasks using shell scripts."

QUESTION 06

What is a Linux Distribution?

⭐⭐⭐⭐⭐ MUST KNOW

A Linux distribution is a complete operating system built around the Linux kernel along with system utilities, libraries, package-management tools and applications.

Distribution Common Usage
Ubuntu Cloud, servers, development
Amazon Linux AWS environments
RHEL Enterprise environments
CentOS / Rocky / AlmaLinux Server environments
Debian Servers and general Linux usage
🎤 Interview Answer

"A Linux distribution is a complete operating system built using the Linux kernel together with system utilities, libraries, package managers and other software. Examples include Ubuntu, Amazon Linux and Red Hat Enterprise Linux."

QUESTION 07

What is the Root User?

⭐⭐⭐⭐⭐

The root user is the Linux superuser with extensive privileges over the system.

The root user can perform administrative operations such as installing software, modifying system configuration and changing permissions.

⚠️ Important

Because root has extensive privileges, administrative access should be used carefully.

🎤 Interview Answer

"Root is the Linux superuser with extensive administrative privileges. Because unrestricted root access can be dangerous, administrative operations should be performed carefully and preferably through controlled privilege escalation."

QUESTION 08

What is sudo?

⭐⭐⭐⭐⭐ VERY COMMON

sudo allows an authorized user to execute a command with elevated privileges.

💡 Example 
sudo apt update

sudo systemctl restart nginx

Instead of logging in directly as root, an administrator can grant controlled administrative privileges to users.

🎤 Interview Answer

"sudo allows an authorized user to execute specific commands with elevated privileges without directly logging in as the root user."

QUESTION 09

What is the Linux File System?

⭐⭐⭐⭐⭐ MUST KNOW

Linux organizes files and directories in a hierarchical structure starting from the root directory represented by /.

/ ├── bin ├── etc ├── home ├── var ├── tmp ├── usr ├── opt └── root
Directory Purpose
/ Root of the filesystem
/home User home directories
/etc System configuration files
/var Variable data such as logs
/tmp Temporary files
/usr User-space programs and resources
/opt Optional/additional application software
/root Home directory of the root user
🎤 Interview Answer

"Linux uses a hierarchical filesystem that starts at the root directory /. Important directories include /etc for configuration, /var for variable data and logs, /home for user directories and /tmp for temporary files."

QUESTION 10

Absolute Path vs Relative Path

⭐⭐⭐⭐
Absolute Path Relative Path
Starts from the root directory Starts from the current directory
Example: /var/log/app.log Example: logs/app.log
Complete location Location relative to current directory
💡 Example 
pwd
/home/nandu

cd /var/log

/var/log is an absolute path. If the current directory is /home/nandu: 

cd projects

projects is a relative path.

QUESTION 11

Basic Linux Commands

⭐⭐⭐⭐⭐ MUST KNOW
Command Purpose
pwd Show current directory
ls List files/directories
cd Change directory
mkdir Create directory
touch Create empty file
cp Copy files/directories
mv Move or rename
rm Remove files/directories
cat Display file content
🔥 Practical Flow 
pwd
ls
mkdir project
cd project
touch app.txt
ls
cat app.txt
QUESTION 12

CLI vs GUI

⭐⭐⭐
CLI GUI
Command Line Interface Graphical User Interface
Commands are typed Uses graphical elements
Common in servers and automation Common for desktop interaction
Easy to automate Usually less convenient for automation
🎤 Interview Answer

"CLI allows users to interact with a system using commands, while GUI provides graphical interaction. CLI is especially important in DevOps because servers are frequently managed remotely and automation relies heavily on command-line tools."

REAL-TIME SCENARIO

🎯 You receive a Linux EC2 server. What would you do first?

⭐⭐⭐⭐⭐ DEVOPS FAVORITE
Connect to Server ↓ Check User ↓ Check Hostname ↓ Check OS ↓ Check CPU / Memory / Disk ↓ Check Network ↓ Check Services / Logs
💡 Example Commands 
whoami
hostname
cat /etc/os-release
uname -r
uptime
free -h
df -h
ip addr
systemctl --type=service
🎤 Strong Interview Answer

"After connecting to a Linux server, I would first verify the current user and host, identify the operating system, and check basic system health such as uptime, CPU, memory and disk usage. Then I would verify networking, running services and relevant logs depending on the issue."
