QUESTION 01

What is Amazon EC2?

CLEAR CONCEPT

Amazon EC2 (Elastic Compute Cloud) is an AWS service that provides resizable virtual servers called instances in the cloud. Instead of purchasing and maintaining a physical server, we can launch an EC2 instance with the required CPU, memory, storage and networking configuration. We can then install an operating system, applications and other software on that instance.

💡 Real-Time Example

Suppose we have a web application that needs a Linux server. Instead of buying a physical server, we can launch an EC2 instance, install Docker, deploy our application and expose it through a Load Balancer.

🎤 Interview Answer

"Amazon EC2 is a compute service provided by AWS that allows us to launch and manage virtual servers in the cloud. We can choose the instance type, operating system, storage and networking configuration based on our application requirements."

QUESTION 02

What is an EC2 instance?

CLEAR CONCEPT

An EC2 instance is a virtual server running inside AWS. When we launch an EC2 instance, AWS allocates computing resources such as CPU, memory, networking and storage according to the configuration we select. The instance runs an operating system such as Amazon Linux, Ubuntu or Windows Server.

💡 Real-Time Example

If our application requires 4 vCPUs and 16 GB RAM, we can select an EC2 instance type that provides those resources and deploy our application on it.

🎤 Interview Answer

"An EC2 instance is a virtual machine provided by AWS. It gives us configurable compute resources such as CPU, memory, networking and storage, allowing us to run applications without managing physical servers."

🔎 Possible Follow-ups
  • How do you launch an EC2 instance?
  • What is an instance type?
  • How do you connect to Linux EC2?
  • How do you secure an EC2 instance?
QUESTION 03

What is an AMI in AWS?

CLEAR CONCEPT

AMI stands for Amazon Machine Image. It is a template used to create EC2 instances. An AMI can contain the operating system, application configuration, installed software and other required settings. When we launch an EC2 instance, we select an AMI as the starting template.

💡 Real-Time Example

Suppose we configured an Ubuntu EC2 server with Docker, Java and our application dependencies. We can create a custom AMI from that configured server and use it to launch additional instances with the same base configuration.

🎤 Interview Answer

"An AMI is a template used to launch EC2 instances. It contains the operating system and can also contain software and configuration required by the application."

🔎 Possible Follow-ups
  • What is a custom AMI?
  • Can we create an AMI from an existing EC2?
  • Can an AMI be copied to another region?
  • What is the relationship between AMI and EBS?
QUESTION 04

What are EC2 instance types?

CLEAR CONCEPT

EC2 instance types define the compute resources available to an EC2 instance. Different instance families are optimized for different workloads. For example:

General Purpose — balanced CPU, memory and networking.
Compute Optimized — workloads requiring high CPU performance.
Memory Optimized — workloads requiring large amounts of RAM.
Storage Optimized — workloads requiring high local storage performance.

💡 Real-Time Example

A normal web application may use a general-purpose instance. A CPU-intensive application may require a compute-optimized instance. A large in-memory database may require a memory-optimized instance.

🎤 Interview Answer

"EC2 instance types determine the compute resources provided to an instance. AWS offers different instance families optimized for general-purpose, compute-intensive, memory-intensive and storage-intensive workloads."

🔎 Possible Follow-ups
  • What is an instance family?
  • How do you choose an instance type?
  • What are vCPUs?
  • What is the difference between CPU and memory optimized instances?
QUESTION 05

What is the difference between stopping and terminating an EC2 instance?

CLEAR CONCEPT

Stop: The instance is shut down, but its EBS-backed storage can remain available. The instance can usually be started again.

Terminate: The instance is permanently deleted. The instance cannot be started again after termination. Therefore, termination should be used carefully.

💡 Real-Time Example

Suppose a development server is not required overnight. We can stop the instance and start it again the next morning. If the server is permanently no longer required, we can terminate it.

🎤 Interview Answer

"Stopping an EC2 instance shuts it down while allowing it to be started again later. Terminating an instance permanently removes it, so it cannot be restarted."

🔎 Possible Follow-ups
  • What happens to the public IP after stopping?
  • What happens to EBS volumes?
  • Does stopping an instance stop all charges?
  • What happens to instance-store data?
QUESTION 06

How do you connect to a Linux EC2 instance?

CLEAR CONCEPT

For a Linux EC2 instance, we commonly connect using SSH. We need the appropriate private key, the instance's reachable IP or hostname, and network access through the Security Group. SSH normally uses port 22.

💡 Real-Time Example

After launching an Ubuntu EC2 instance, we can connect from a terminal using the instance's public IP and the corresponding private key.

🎤 Interview Answer

"I connect to a Linux EC2 instance using SSH. I make sure the instance is reachable, port 22 is allowed from the required source in the Security Group, and I use the correct private key with the appropriate SSH username."

💻 Example Command 
ssh -i my-key.pem ubuntu@<public-ip>
🔎 Possible Follow-ups
  • Why is port 22 required?
  • What if SSH connection times out?

  • What is the difference between public and private IP?

QUESTION 07

What is a Security Group in EC2?

CLEAR CONCEPT

A Security Group is a virtual firewall associated with AWS resources such as EC2 instances. It controls network traffic using inbound and outbound rules. Security Groups are stateful, meaning response traffic for an allowed connection is automatically allowed.

💡 Real-Time Example

For a web server, we may allow HTTP on port 80 and HTTPS on port 443 from the internet. For SSH, instead of allowing port 22 from everyone, we should restrict access to a trusted IP range.

🎤 Interview Answer

"A Security Group acts as a stateful virtual firewall for an EC2 instance. It controls inbound and outbound traffic through rules."

🔎 Possible Follow-ups
  • Are Security Groups stateful or stateless?
  • Can a Security Group deny traffic?
  • Security Group vs NACL?
  • Can one EC2 have multiple Security Groups?
QUESTION 08

What is EBS and how is it related to EC2?

CLEAR CONCEPT

Amazon EBS stands for Elastic Block Store. It provides persistent block-level storage that can be attached to EC2 instances. The operating system and application data can be stored on EBS volumes. Unlike temporary instance-store storage, EBS data is designed to persist independently of the running instance lifecycle in many common scenarios.

💡 Real-Time Example

If an EC2 instance is used as an application server, an EBS volume can be used to store application files, logs or database data.

🎤 Interview Answer

"EBS is persistent block storage for EC2. We can attach EBS volumes to EC2 instances and use them for operating-system, application or data storage."

🎯 Real-Time EC2 Scenarios

SCENARIO 01

Your EC2 instance is running, but you cannot connect using SSH. What will you check?

TROUBLESHOOTING APPROACH

I would troubleshoot layer by layer instead of immediately assuming that the EC2 instance itself is down.

🛠️ Troubleshooting Checklist

1. Check whether the instance is actually running.
2. Verify the correct public IP or reachable private address.
3. Check the Security Group and confirm that TCP port 22 is allowed from the required source.
4. Check the subnet route table and internet connectivity if using a public IP.
5. Check Network ACL rules.
6. Verify the SSH username.
7. Verify the correct private key.
8. Check whether the operating system's SSH service is running.

🎤 Interview Answer

"If SSH is failing, I first check the EC2 instance state and connectivity. Then I verify the IP address, Security Group port 22 rule, subnet routing, Network ACLs, SSH credentials and finally the SSH service on the operating system."

SCENARIO 02

Your EC2 application is running but users cannot access the website. How would you troubleshoot it?

PRODUCTION SCENARIO

I would check the complete request path from the client to the application.

🛠️ Troubleshooting Flow

Client → DNS → Load Balancer / Public IP → Security Group → Network ACL → EC2 → Application → Application Port

🎤 Interview Answer

"I would first identify whether the problem is DNS, network connectivity, security rules, EC2 availability or the application itself. I would verify the Security Group, routes, listening ports, application process and logs before making changes."

🧠 Study Tip:

Don't memorize only the interview answer. First understand the concept, then understand the real-time example, and finally practice explaining it in your own words. The interviewer may change the wording of the question, but if you understand the concept, you can still answer.
